# 基本推导
先设：

$ N=2^{\mathrm{SF}},
\qquad
R=\mathrm{OS} $

一个过采样 LoRa symbol 有：

$ NR $

个采样点。过采样 dechirp 后的序列记为：

$ z[n],
\qquad
n=0,\dots,NR-1 $

它的全长 $ NR $-point DFT 定义为：

$ Z[K]
=
\sum_{n=0}^{NR-1}
z[n]e^{-j2\pi Kn/(NR)} $

对应的反变换是：

$ z[n]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kn/(NR)} $

---

## 1. 取第 $ q $ 路 branch
现在取第 $ q $ 路 branch：

$ z_q[p]
=
z[pR+q],
\qquad
p=0,\dots,N-1 $

也就是每隔 $ R $ 个点取一个，第 $ q $ 路从 offset $ q $ 开始取。

对这一路做 $ N $-point DFT：

$ Y_q[m]
=
\sum_{p=0}^{N-1}
z[pR+q]e^{-j2\pi mp/N} $

接下来把 $ z[pR+q] $ 用全长 DFT 的反变换代进去：

$ z[pR+q]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(pR+q)/(NR)} $

所以：

$ Y_q[m]
=
\sum_{p=0}^{N-1}
\left[
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(pR+q)/(NR)}
\right]
e^{-j2\pi mp/N} $

把求和顺序换一下：

$ Y_q[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kq/(NR)}
\sum_{p=0}^{N-1}
e^{j2\pi KpR/(NR)}
e^{-j2\pi mp/N} $

注意：

$ \frac{KpR}{NR}
=
\frac{Kp}{N} $

所以里面关于 $ p $ 的部分变成：

$ \sum_{p=0}^{N-1}
e^{j2\pi Kp/N}
e^{-j2\pi mp/N}
=
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N} $

这个求和是一个标准几何级数：

$ \sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
=
\begin{cases}
N, & K-m \equiv 0 \pmod{N}\\
0, & \text{otherwise}
\end{cases} $

也就是说，只有当：

$ K
=
m+\ell N $

时才会留下来。其中：

$ \ell=0,1,\dots,R-1 $

因为 $ K $ 的范围是 $ 0,\dots,NR-1 $。

于是原式只剩下这些 $ K=m+\ell N $ 的项：

$ Y_q[m]
=
\frac{1}{NR}
\sum_{\ell=0}^{R-1}
Z[m+\ell N]
e^{j2\pi q(m+\ell N)/(NR)}
\cdot N $

前面的系数是：

$ \frac{N}{NR}
=
\frac{1}{R} $

所以得到：

$ Y_q[m]
=
\frac{1}{R}
\sum_{\ell=0}^{R-1}
Z[m+\ell N]
e^{j2\pi q(m+\ell N)/(NR)} $

** 折叠周期是 N 个 full-FFT bin，对应标准 LoRa Nyquist-rate 解调下的一整个符号频率网格。  **

---

## 2. 这个式子的物理含义
这个式子的物理含义是：

$ \boxed{
\text{第 }q\text{ 路 branch 的 bin }m
=
\text{全 }NR\text{ 点频谱中 }m,m+N,m+2N,\dots,m+(R-1)N\text{ 的线性组合}
} $

也就是说，branch DFT 不是凭空生成一个新频谱，而是把过采样全频谱中**相隔 **$ N $** 个 bin 的频谱切片 alias 到一起。**

---

## 3. 放回 LoRa 场景
如果** dechirp 后真实信号在全长 **$ NR $**-point 频谱里主要落在：**

$ K=k $

那么对 branch bin $ m=k $：

$ Y_q[k]
\approx
\frac{1}{R}
Z[k]e^{j2\pi qk/(NR)} $

但是这个式子，**在SNR比较低的时候k+lN那些位置可能无可避免的会出现很多高度不容忽视的噪声，所以这个近似将不成立**

所以不同 branch 之间差的就是这个确定性相位：

$ e^{j2\pi qk/(NR)} $

因此你要相干叠加，就乘反向相位：

$ Y_q[k]e^{-j2\pi qk/(NR)} $

再求和：

$ S[k]
=
\sum_{q=0}^{R-1}
Y_q[k]e^{-j2\pi qk/(NR)} $

这就是你现在“过采样拆 branch，然后相位对齐叠加”的数学根。

# 非均匀采样
## 基本推导
定义**第 **$ b $** 路 branch 的普通 **$ N $**-point DFT**：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
z[Rp+c_b[p]]
e^{-j2\pi mp/N} $

令 full $ NR $-point DFT 为：

$ Z[K]
=
\sum_{n=0}^{NR-1}
z[n]e^{-j2\pi Kn/(NR)} $

反变换为：

$ z[n]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kn/(NR)} $

代入 $ Y_b[m] $：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
\left[
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(Rp+c_b[p])/(NR)}
\right]
e^{-j2\pi mp/N} $

交换求和顺序：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]
\sum_{p=0}^{N-1}
e^{j2\pi K(Rp+c_b[p])/(NR)}
e^{-j2\pi mp/N} $

因为：

$ \frac{K Rp}{NR}
=
\frac{Kp}{N} $

所以：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
e^{j2\pi Kc_b[p]/(NR)} $

这就是更一般的式子。

也可以写成：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]H_b(m,K) $

其中：

$ H_b(m,K)
=
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
e^{j2\pi Kc_b[p]/(NR)} $

这个 $ H_b(m,K) $ 就是你的非均匀 branch pattern 对 full-spectrum bin $ K $ 到 branch bin $ m $ 的混合权重。

也就是说，非均匀 branch 不再像固定 offset branch 那样，只把：

$ K=m+\ell N $

这些 bin 精确折叠到 $ m $。而是通过<font style="background-color:#FBDE28;"> </font>$ H_b(m,K) $**<font style="background-color:#FBDE28;"> 给每个 full-spectrum bin </font>**$ K $**<font style="background-color:#FBDE28;"> 一个 pattern-dependent 的混合权重。</font>**

因此可以把它理解成：

> 固定 offset branch 的混合权重是规则 aliasing；  
非均匀 branch 的混合权重是由 $ c_b[p] $ 决定的非规则投影。
>

我们不是凭空制造新的物理副本，而是**从过采样 IQ 中构造多个不均匀采样视角**。每个视角都可以恢复或投影出一个候选 LoRa tone 的观测结果。真实 bin 在这些视角下应该稳定，而噪声假峰和 alias 泄漏在不同 pattern 下会表现不一致。因此，这些“重构副本”的价值不是增加独立能量来源，而是提供多视角一致性和假峰去相关。  

## 不同采样pattern
非均匀 pattern 的采样点是：

$ n_{b,p}
=
Rp+c_b[p] $

如果要测试候选 bin $ m $，**正确的 matched projection 应该写成**：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
z[Rp+c_b[p]]
e^{-j2\pi m(Rp+c_b[p])/(NR)} $

# 实验1：噪声向量相干
噪声项：$ \boldsymbol{\eta}
=
\begin{bmatrix}
\eta_1\\
\eta_2\\
\vdots\\
\eta_B
\end{bmatrix} $不是独立的。因为**不同非均匀 pattern 会复用同一批原始采样点。**

于是噪声协方差是：

$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}
\boldsymbol{\eta}^{H}
\right] $

这里不要再额外引入新的 $ \mathbf{S} $。沿用前面的投影矩阵记号，把第 $ b $ 条 pattern 在候选 $ m $ 下的采样权重写成 $ \mathbf{W}_m $ 的第 $ b $ 行。

$ \mathbf{W}_m \in \mathbb{C}^{B\times NR} $

其中 $ NR $ 列对应一个 LoRa symbol 过采样 dechirp 后的 $ NR $ 个时域采样点。第 $ b $ 行的元素是：

$ [\mathbf{W}_m]_{b,n}
=
\begin{cases}
\dfrac{1}{\sqrt{N}}s_m^*[n], & n=n_{b,p}=Rp+c_b[p]\text{ for some }p,\\
0, & \text{otherwise}.
\end{cases} $

于是噪声向量可以写成：

$ \boldsymbol{\eta}(m)
=
\mathbf{W}_m\mathbf{w} $

其中：

$ \mathbf{w}
=
\begin{bmatrix}
w[0]\\
w[1]\\
\vdots\\
w[NR-1]
\end{bmatrix} $

表示同一个 symbol 的 $ NR $ 个采样点上叠加的噪声分量。

如果原始采样噪声是白噪声：

$ \mathbb{E}[\mathbf{w}\mathbf{w}^H]
=
\sigma^2\mathbf{I}_{NR} $

那么：

$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right]
=
\mathbb{E}
\left[
\mathbf{W}_m\mathbf{w}\mathbf{w}^H\mathbf{W}_m^H
\right]
=
\sigma^2\mathbf{W}_m\mathbf{W}_m^H $

如果把噪声功率 $ \sigma^2 $ 归一化为 1，就得到：

$ \mathbf{C}
=
\mathbf{W}_m\mathbf{W}_m^H $

这个矩阵的含义是：

$ C_{ij}
=
\text{第 } i \text{ 条 pattern 和第 } j \text{ 条 pattern 的噪声相关性} $

如果两条 pattern 大量复用同样的采样点，那么：

$ |C_{ij}| $

就会很大。

---

## 正确的相干增益
如果噪声相关，**最佳线性合并不能简单求和**，而要用：

$ \mathbf{C}^{+} $

其中 $ \mathbf{C}^{+} $ 是伪逆。

### 最佳线性组合
这里的“最佳线性合并”指的是：

> 已经有很多个 pattern 输出：
>
> $ y_1,y_2,\dots,y_B $
>
> 我们想把它们加权合成一个数，用来判断候选 bin $ m $ 是否是真的。
>

最一般的线性合并就是：

$ T
=
w_1^*y_1+w_2^*y_2+\cdots+w_B^*y_B $

写成向量：

$ T
=
\mathbf{w}^H\mathbf{y} $

其中：

$ \mathbf{w}
=
\begin{bmatrix}
w_1\\
w_2\\
\vdots\\
w_B
\end{bmatrix} $

就是我们要选的权重。

---

现在 pattern 输出模型是：

$ \mathbf{y}
=
\mathbf{a}x+\boldsymbol{\eta} $

代入：

$ T
=
\mathbf{w}^H
\left(
\mathbf{a}x+\boldsymbol{\eta}
\right) $

所以：

$ T
=
\underbrace{\mathbf{w}^H\mathbf{a}x}_{\text{合并后的信号}}
+
\underbrace{\mathbf{w}^H\boldsymbol{\eta}}_{\text{合并后的噪声}} $

我们希望什么？

**希望信号大，噪声小。**

合并后的信号幅度和：

$ |\mathbf{w}^H\mathbf{a}| $

有关。

合并后的噪声方差是：

$ \mathbb{E}
\left[
|\mathbf{w}^H\boldsymbol{\eta}|^2
\right]
=
\mathbf{w}^H\mathbf{C}\mathbf{w} $

其中：

$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right] $

所以这个合并器的输出 SNR，忽略 $ |x|^2 $（这个我玩意和W无关），就是：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

**“最佳线性合并”就是：**

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
} $

**也就是在所有线性权重 **$ \mathbf{w} $** 里面，找一个让输出 SNR 最大的权重。**

---

### 最优匹配能量
理论最优的匹配能量是：

$ \mathbf{a}^{H}
\mathbf{C}^{+}
\mathbf{a} $

所以我定义：

$ \mathrm{effective\_replicas}
=
\frac{
\mathbf{a}^{H}
\mathbf{C}^{+}
\mathbf{a}
}{N} $

这个量的意思是：

> **这一堆 pattern，在正确扣掉噪声相关性以后，等效于多少条独立的 **$ \sqrt{N} $** 副本？**
>

**推导过程如下：**

目标是求：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

也就是：

$ \max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

其中：

+ $ \mathbf{w} $：线性合并权重；
+ $ \mathbf{a} $：目标响应向量；
+ $ \mathbf{C} $：噪声协方差矩阵。

---

#### 先假设 $ \mathbf{C} $ 可逆
因为 $ \mathbf{C} $ 是噪声协方差矩阵，所以它是 Hermitian 正定矩阵，可以写成：

$ \mathbf{C}
=
\mathbf{C}^{1/2}\mathbf{C}^{1/2} $

令：

$ \mathbf{u}
=
\mathbf{C}^{1/2}\mathbf{w} $

则：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

---

#### 先看分母
分母是：

$ \mathbf{w}^H\mathbf{C}\mathbf{w} $

代入：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

得到：

$ \mathbf{w}^H\mathbf{C}\mathbf{w}
=
(\mathbf{C}^{-1/2}\mathbf{u})^H
\mathbf{C}
(\mathbf{C}^{-1/2}\mathbf{u}) $

因为 $ \mathbf{C} $ 是 Hermitian，所以 $ \mathbf{C}^{-1/2} $ 也是 Hermitian：

$ (\mathbf{C}^{-1/2})^H
=
\mathbf{C}^{-1/2} $

于是：

$ (\mathbf{C}^{-1/2}\mathbf{u})^H
=
\mathbf{u}^H\mathbf{C}^{-1/2} $

所以：

$ \mathbf{w}^H\mathbf{C}\mathbf{w}
=
\mathbf{u}^H
\mathbf{C}^{-1/2}
\mathbf{C}
\mathbf{C}^{-1/2}
\mathbf{u} $

而：

$ \mathbf{C}^{-1/2}
\mathbf{C}
\mathbf{C}^{-1/2}
=
\mathbf{I} $

所以：

$ \boxed{
\mathbf{w}^H\mathbf{C}\mathbf{w}
=
\mathbf{u}^H\mathbf{u}
=
\|\mathbf{u}\|^2
} $

---

#### 再看分子
分子是：

$ |\mathbf{w}^H\mathbf{a}|^2 $

代入：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

有：

$ \mathbf{w}^H\mathbf{a}
=
(\mathbf{C}^{-1/2}\mathbf{u})^H\mathbf{a} $

$ =
\mathbf{u}^H\mathbf{C}^{-1/2}\mathbf{a} $

定义：

$ \mathbf{b}
=
\mathbf{C}^{-1/2}\mathbf{a} $

于是：

$ \boxed{
|\mathbf{w}^H\mathbf{a}|^2
=
|\mathbf{u}^H\mathbf{b}|^2
} $

所以 SNR 变成：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{u}^H\mathbf{b}|^2
}{
\|\mathbf{u}\|^2
} $

---

#### 用柯西-施瓦茨不等式
现在用柯西-施瓦茨不等式：

$ |\mathbf{u}^H\mathbf{b}|
\leq
\|\mathbf{u}\|\|\mathbf{b}\| $

两边平方：

$ |\mathbf{u}^H\mathbf{b}|^2
\leq
\|\mathbf{u}\|^2\|\mathbf{b}\|^2 $

所以：

$ \frac{
|\mathbf{u}^H\mathbf{b}|^2
}{
\|\mathbf{u}\|^2
}
\leq
\|\mathbf{b}\|^2 $

因此最大 SNR 是：

$ \max_{\mathbf{w}}
\mathrm{SNR}(\mathbf{w})
=
\|\mathbf{b}\|^2 $

代回：

$ \mathbf{b}
=
\mathbf{C}^{-1/2}\mathbf{a} $

得到：

$ \|\mathbf{b}\|^2
=
(\mathbf{C}^{-1/2}\mathbf{a})^H
(\mathbf{C}^{-1/2}\mathbf{a}) $

$ =
\mathbf{a}^H
(\mathbf{C}^{-1/2})^H
\mathbf{C}^{-1/2}
\mathbf{a} $

因为：

$ (\mathbf{C}^{-1/2})^H
=
\mathbf{C}^{-1/2} $

所以：

$ \|\mathbf{b}\|^2
=
\mathbf{a}^H
\mathbf{C}^{-1/2}
\mathbf{C}^{-1/2}
\mathbf{a} $

也就是：

$ \boxed{
\|\mathbf{b}\|^2
=
\mathbf{a}^H\mathbf{C}^{-1}\mathbf{a}
} $

所以如果 $ \mathbf{C} $ 可逆：

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
=
\mathbf{a}^H\mathbf{C}^{-1}\mathbf{a}
} $

---

#### 最优权重是什么？
取等号时，柯西-施瓦茨要求：

$ \mathbf{u}
\propto
\mathbf{b} $

也就是：

$ \mathbf{u}
\propto
\mathbf{C}^{-1/2}\mathbf{a} $

又因为：

$ \mathbf{u}
=
\mathbf{C}^{1/2}\mathbf{w} $

所以：

$ \mathbf{C}^{1/2}\mathbf{w}
\propto
\mathbf{C}^{-1/2}\mathbf{a} $

两边左乘：

$ \mathbf{C}^{-1/2} $

得到：

$ \boxed{
\mathbf{w}
\propto
\mathbf{C}^{-1}\mathbf{a}
} $

这就是最优线性合并权重。

---

#### 如果 $ \mathbf{C} $ 不可逆
如果 $ \mathbf{C} $ 不可逆，把逆换成伪逆。

做特征分解：

$ \mathbf{C}
=
\mathbf{U}_r\boldsymbol{\Lambda}\mathbf{U}_r^H $

其中 $ \boldsymbol{\Lambda} $ 只包含非零特征值。

伪逆是：

$ \mathbf{C}^+
=
\mathbf{U}_r\boldsymbol{\Lambda}^{-1}\mathbf{U}_r^H $

在 $ \mathbf{a}\in\operatorname{Range}(\mathbf{C}) $ 的前提下，同样的白化推导只在有效子空间里做，于是：

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
=
\mathbf{a}^H\mathbf{C}^+\mathbf{a}
} $

最小范数的最优权重是：

$ \boxed{
\mathbf{w}_{\mathrm{opt}}
\propto
\mathbf{C}^+\mathbf{a}
} $

如果你想要单位增益归一化，让：

$ \mathbf{w}^H\mathbf{a}
=
1 $

可以取：

$ \boxed{
\mathbf{w}_{\mathrm{opt}}
=
\frac{
\mathbf{C}^+\mathbf{a}
}{
\mathbf{a}^H\mathbf{C}^+\mathbf{a}
}
} $

这就是从你给的 SNR 形式推到 $ \mathbf{a}^H\mathbf{C}^+\mathbf{a} $ 的过程。

## 非均匀 pattern 的实验结果
如果非均匀 pattern 真创造了额外独立副本，我们应该看到：

$ \mathrm{effective\_replicas}
>
4 $

但实际算出来：

$ \mathrm{fixed}
=
4.000000 $

$ \mathrm{basic}
=
4.000000 $

$ \mathrm{dither}
=
4.000000 $

$ \mathrm{search}
=
4.000000 $

$ \mathrm{basic\_only}
=
4.000000 $

$ \mathrm{random\_only}
\approx
3.91 $

所以结论是：

$ \text{非均匀 pattern 可以相干，但不能超过 OSR 的独立自由度。} $

更直白地说：

$ \text{信号项对齐了，但噪声项也高度相关。} $

额外 pattern 带来的表面增益，被：

$ \mathbf{C}^{+} $

扣掉以后，就不再是新的独立能量。

---

## 当前最准确的判断
所以现在最准确的判断是：

$ \text{非均匀采样不是能量增强器，而是候选重排器。} $

它可能有用的地方不是：

$ \text{造出超过 } R \text{ 个独立副本} $

而是：

$ \text{改变错误 bin 和正确 bin 的相对排序} $

这也是为什么我们看到：

$ \mathrm{GLS/whitened}
\approx
\mathrm{Savaux} $

而某些随机 mean/coherent 偶尔会小赢一点点。它不是物理 SNR 增益，而是排序偏置。

---

## 新一轮尝试：把非均匀采样当作假峰一致性检测器

这一轮没有继续把非均匀 pattern 当作“更多相干副本”，而是换了一个更保守的角度：

$ \text{Savaux 负责主能量检测，非均匀 pattern 负责检查这个候选峰稳不稳。} $

对每个候选 bin $ k $，每条 pattern 给出一个输出：

$
Y_b[k]
$

把所有 pattern 堆起来就是：

$
\mathbf{y}[k]
=
\begin{bmatrix}
Y_1[k]\\
Y_2[k]\\
\vdots\\
Y_B[k]
\end{bmatrix}
$

如果这个候选真的是目标 bin，那么 LoRa-corrected 后不同 pattern 的输出应该比较同相、比较一致。

所以定义 pattern 一致性：

$
\gamma[k]
=
\frac{
\left|
\frac{1}{B}
\sum_{b=1}^{B}
Y_b[k]
\right|^2
}{
\frac{1}{B}
\sum_{b=1}^{B}
\left|
Y_b[k]
\right|^2
}
$

其中：

$
0
\le
\gamma[k]
\le
1
$

如果所有 pattern 输出完全同相，则：

$
\gamma[k]
\approx
1
$

如果这些输出主要是互相不稳定的噪声假峰，则：

$
\gamma[k]
$

会更小。

于是新的稳定性重排分数是：

$
\mathrm{stable\_score}[k]
=
\mathrm{SavauxPower}[k]
\cdot
\gamma[k]
$

这句话非常重要：

$ \mathrm{stable\_score} $

不是新的最大似然能量，也不是新的独立副本合并。

它只是：

$
\text{用非均匀 pattern 的一致性去惩罚不稳定假峰。}
$

代码对应：

$
\texttt{stable\_pattern}
$

以及更保守的：

$
\texttt{gated\_consensus\_pattern}
$

其中 gated consensus 的规则是：

1. Savaux 峰值 margin 足够大时，不改 Savaux。
2. 只有 Savaux 自己也不太确定时，才允许非均匀 pattern 参与重排。
3. mean-pattern 和 stable-pattern 同意同一个替代 bin，才真的切换。

目前实验结果是小赢，但还不是大胜。

在 $0\_0\_0\_10\_14\_16$、2 个 packet、$-24/-25/-26$ dB、4 个噪声 seed、共 840 个 payload symbol 上：

| 方法 | 错误数 | SER | 修正 Savaux | 破坏 Savaux | 改动数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Savaux | 236 | 0.280952 | 0 | 0 | 0 |
| stable-pattern | 233 | 0.277381 | 15 | 12 | 71 |
| gated-consensus | 233 | 0.277381 | 3 | 0 | 5 |

默认三个数据集、每个 1 个 packet、$-25/-26$ dB、3 个噪声 seed、共 630 个 payload symbol 上：

| 方法 | 错误数 | SER | 修正 Savaux | 破坏 Savaux | 改动数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Savaux | 309 | 0.490476 | 0 | 0 | 0 |
| stable-pattern | 307 | 0.487302 | 8 | 6 | 70 |
| gated-consensus | 309 | 0.490476 | 1 | 1 | 8 |

所以现在的阶段性结论是：

$
\boxed{
\text{非均匀 pattern 确实能提供一点候选排序信息，但目前增益还很小。}
}
$

它最像一个“弱仲裁器”：

$
\text{当 Savaux 峰值非常接近时，帮忙判断哪个候选更稳定。}
$

但它还没有强到可以替代 Savaux，也还没有证明在所有数据集上稳定降低 SER。

## 进一步结果：gated-hybrid mean 重排器

继续做候选级诊断以后发现：

Savaux 错的符号里，很多时候正确 bin 其实已经在 Savaux 的 top-k 里面。

但是只看 pattern 一致性：

$
\gamma[k]
$

不够强，因为正确 bin 的一致性有时反而不比 Savaux 假峰高。

更有效的是把 Savaux 主能量和非均匀 pattern 的 mean-power 做几何融合：

$
\mathrm{hybrid\_score}[k]
=
\mathrm{SavauxPower}[k]
\left(
\frac{
\mathrm{MeanPatternPower}[k]
}{
\mathrm{SavauxPower}[k]
}
\right)^{\beta}
$

等价于：

$
\mathrm{hybrid\_score}[k]
=
\mathrm{SavauxPower}[k]^{1-\beta}
\mathrm{MeanPatternPower}[k]^{\beta}
$

目前小网格里最好的参数是：

$
\beta
=
0.75
$

也就是说：

$
\text{仍然保留 Savaux 的主排序，但更相信非均匀 mean-power。}
$

不过裸 hybrid 会太激进，所以必须加 gate：

1. 只允许 Savaux top-3 里面的候选挑战 top-1。
2. 新候选的 hybrid score 必须超过 Savaux 候选的 $1.1$ 倍。
3. Savaux top-1/top-2 margin 大于 $1.5\mathrm{dB}$ 时，不切换。

这个版本代码里叫：

$
\texttt{gated\_hybrid\_pattern}
$

默认三个数据集、每个 2 个 packet、$-25/-26$ dB、3 个噪声 seed、共 1260 个 payload symbol 上：

| 方法 | 错误数 | SER | 修正 Savaux | 破坏 Savaux | 改动数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Savaux | 466 | 0.369841 | 0 | 0 | 0 |
| stable-pattern | 469 | 0.372222 | 16 | 19 | 112 |
| hybrid-mean 裸重排 | 485 | 0.384921 | 33 | 52 | 209 |
| gated-hybrid | 457 | 0.362698 | 14 | 5 | 85 |
| gated-consensus | 464 | 0.368254 | 2 | 0 | 9 |

同一批噪声 realization 下，其他 baseline 的总账是：

| 方法 | 错误数 | SER |
| --- | ---: | ---: |
| Savaux oversampled | 466 | 0.369841 |
| LoRaTrimmer | 602 | 0.477778 |
| SymFEC | 987 | 0.783333 |
| UniChirp | 715 | 0.567460 |
| gated-hybrid non-uniform | 457 | 0.362698 |

所以目前最强的阶段性结论更新为：

$
\boxed{
\text{非均匀采样目前最有价值的用法，是 gated hybrid 候选重排。}
}
$

它不是增加独立相干能量，而是：

$
\text{用非均匀 mean-power 去纠正 Savaux 在低置信度场景下的排序错误。}
$

这已经在小样本上超过了当前几个 baseline，但增益仍然不大，所以后面还要继续找更稳、更大的净修正空间。

## 停止继续微调这个方向

后面把验证范围扩大以后，这条路的上限更清楚了。

在 $-24/-25/-26\mathrm{dB}$、三个数据集、每个数据集 3 个 packet、噪声 seed 为 $1,2,42$ 的 2835 个 payload symbol 上：

| 方法 | 错误数 | SER | 相对 Savaux |
| --- | ---: | ---: | ---: |
| Savaux | 837 / 2835 | 0.295238 | 0 |
| gated-hybrid 原版 | 833 / 2835 | 0.293827 | 净修 4 个 |
| gated-hybrid 加 consistency | 825 / 2835 | 0.291005 | 净修 12 个 |

在更正常一点的 $-22/-23/-24\mathrm{dB}$ 上：

| 方法 | 错误数 | SER | 相对 Savaux |
| --- | ---: | ---: | ---: |
| Savaux | 384 / 2835 | 0.135450 | 0 |
| gated-hybrid 加 consistency | 381 / 2835 | 0.134392 | 净修 3 个 |

这个不是我们要找的那种：

$
0.2
\rightarrow
0.1
$

级别的 SER 跃迁。

所以这里应该停下：

$
\boxed{
\text{不要继续围绕 stable / hybrid / gated-hybrid 做参数微调。}
}
$

当前证据说明它只是一个很弱的候选重排扰动：

1. 有时能修 Savaux 的个别错。
2. 也会破坏 Savaux 已经正确的符号。
3. 净收益太小，不值得继续扫阈值。

如果还要继续非均匀采样方向，必须换成质变思路，而不是继续调这个 reranker。

更值得另开分支的方向是：

1. 在 Savaux 前面改进 timing / CFO / SFO 估计，而不是在 Savaux 后面重排。
2. 把编码约束、payload 约束、soft-decision 反馈接进来。
3. 跨多个符号估计噪声/干扰模型，而不是只在单个 symbol 内拿 pattern 做投票。
4. 重新设计观测模型，真的改变前端信息量，而不是重组同一批过采样点。

## 顺手排除：固定 oversampling origin 不是问题

因为 reranker 没有大收益，所以又检查了一下 Savaux baseline 是不是只是用了错误的过采样 origin。

当前 baseline 默认：

$
\mathrm{origin\_shift}
=
\frac{R}{2}
=
2
$

扫 $0,1,2,3$ 四个固定 origin，在 $-22/-23/-24\mathrm{dB}$、三个数据集、每个 3 个 packet、seed 为 $1,2,42$ 的 2835 个 payload symbol 上：

| origin shift | 错误数 | SER |
| ---: | ---: | ---: |
| 0 | 1884 / 2835 | 0.664550 |
| 1 | 587 / 2835 | 0.207055 |
| 2 | 384 / 2835 | 0.135450 |
| 3 | 591 / 2835 | 0.208466 |

所以：

$
\boxed{
\text{当前 Savaux 用的固定 origin shift=2 已经是最好的固定分支。}
}
$

剩下的错误不是简单换一个过采样 offset 就能解决的。

## 中等 SNR 下的上界检查

按照新的判断标准，不应该只看 $-25\mathrm{dB}$ 以下。

所以重新看 $-22/-23/-24\mathrm{dB}$、三个数据集、每个 3 个 packet、seed 为 $1,2,42$，一共 2835 个 payload symbol。

当前 baseline 总账：

| 方法 | 错误数 | SER |
| --- | ---: | ---: |

目前最好的非均匀 gated-hybrid reranker 只有：

| 方法 | 错误数 | SER |
| --- | ---: | ---: |
| gated-hybrid non-uniform | 381 / 2835 | 0.134392 |

也就是只净修 3 个 symbol。

这个没有意义。

但是 Savaux top-k oracle 暴露了另一个事实：

| 选择器 | 错误数 | SER |
| --- | ---: | ---: |
| Savaux top-1 | 384 / 2835 | 0.135450 |
| top-2 内 oracle | 317 / 2835 | 0.111817 |
| top-4 内 oracle | 268 / 2835 | 0.094533 |
| top-8 内 oracle | 240 / 2835 | 0.084656 |
| top-16 内 oracle | 212 / 2835 | 0.074780 |

这说明：

$
\text{Savaux 的候选列表里确实藏着不少正确答案。}
$

但：

$
\text{非均匀 pattern 的一致性/mean-power 还不足以把它们稳定选出来。}
$

所以真正有希望的下一条路不是继续加 pattern，而是：

$
\boxed{
\text{top-k soft decision + 编码/载荷约束。}
}
$

也就是说，用 Savaux 或非均匀 pattern 生成候选和软信息，然后让编码结构、payload 结构、CRC 或跨符号一致性来选。

如果做不到这个层级，就不要继续在单符号非均匀重排上消耗时间。
