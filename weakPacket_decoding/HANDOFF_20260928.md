## 1. 问题聚焦（论文主张）

深度弱信号区（同步估计已不可靠时），解码链赖以决策的每符号软似然被
分数 bin 失配系统性污染；且同步与解码的资源不对等——副本分集全部喂给
了解码，同步零分集运行。论文解决：
**免估计地对齐不确定性下输出可信软证据（GLRT/边际化 + 相干重组），
并把同一份能量副本接入同步（检测级联）。**

## 2. 已验证事实（本日，全部可复现）

`data/experiments/oversampling_accounting_20260928/`（脚本+results.json+图+RESULTS.md）：

1. **反相双峰（精确）**：分数 bin 音的相邻双峰相位差恒为 −π(N−1)/N，
   幅值比 sin(πκ/N)/sin(π(1−κ)/N) ≈ κ/(1−κ)，与增益/初相/SNR 无关。
2. **整数 chip 偏移零损耗**：preamble 单峰搬到 bin N−d，其余 bin 恒为 0
   （`frame_sync_impl.cc:557` 的 k_hat↔N−STO 关系由此而来）。
3. **量化税实测**：chip 网格量化（残余 κ~U(−0.5,0.5)）= 1.5–2 dB +
   κ→0.5 悬崖（SER ×3.7）+ ~5% 地板；已知 κ 的相干旋转完全消除（R5=R1）。
4. **过采样相位有真分集（有条件）**：噪声带宽覆盖过采样带（前端未滤波）
   时，4 相位功率平均 = 4 阶非相干合并，实测 +2.2 dB；朴素平均留了 ~3 dB
   相位错开损失在桌上 → **相位对齐合并预测 ≈ +5~6 dB（≈R6），无需重传**。
   （噪声若已预滤波到带内则该增益消失——需检查我们链路的抽取前滤波。）
5. **bin 对能量和不能当 N 元 argmax 统计量**（56% 地板，极值统计），
   只能做 top 候选两两重排。纠错记录在案。
6. **同步−解码 gap = 6.1 dB ≈ 10log10(4)**（SF12 档案数字：PC-Ridge
   同步地板 −24.5 dB per-sample；K=4 副本解码 −30.6 dB；K=8 −33.6 dB，
   K4→K8 增益 2.9 dB≈3.0 ✓）。会话口头的"−18/−25 dB"系记岔。

## 3. 方法设计（待实现，按优先级）

1. **κ̂ 5 点核拟合**（P0，已定位的唯一算法缺口）：补零网格主瓣宽，
   相邻幅值比失效；用 5 点窗做 Dirichlet 核形状拟合估 κ，目标把 NEW-2
   推到 ORACLE −0.5 dB 内。随后：检查 frame_sync/PC-Ridge 前导是否只用
   单一抽取相位（若是，NEW 解调直接接入同步，+5 dB 兑现到同步门限）。
2. **接入真实链**（P1）：NEW-2 的 T(s) 替换 weak_decoder 的 Savaux 谱
   入口，跑 ambiguity-ridge + soft-Hamming + CRC 仲裁全套，量 PDR50。
3. **检测级联**（P1）：能量门删除；滑动去斜-FFT 谱图不设硬门；
   S(b,t) 沿 8 窗积累（bin 对只用于 top 候选重排！）；Top-K 软候选进
   decode 仲裁；跨副本检测统计量合并 +10log10(K)。
4. **判据分层**：逐符号相位判决数学封死（半 bin 命题，已有仿真版证明）；
   正确用法是似然模型 + 包级一致性（CRC 之外的第二判据）。
5. **OTA 重放**：现有 8× capture 过 NEW 解调层，对照 strict 链 PDR。
