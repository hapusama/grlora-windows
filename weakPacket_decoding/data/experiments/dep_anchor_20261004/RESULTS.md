# dep_anchor_20261004（M2）——拆分认证可部署检测器 dep2：前导相干锚 + 解析门限族

任务：把 dep（可部署臂）相对 cert 的 ~3dB H0 折扣吃回来，使系统级检测对
DeRa port 形成 ≥+2dB 稳定优势（预注册判定：无漂移 Pd=0.9@FAR=1e-3 下
dep-新 ≥ +2.0dB 且漂移域全 δ ≥ +1.5dB、配对负局 <10% = 突破；+1~2dB =
部分；<1dB = 失败诊断）。

脚本前缀 m2_；数据 = SF10 OTA 28 帧（与 keystone_battle/d2 完全同帧集）。

## 0. 铁律遵守声明

- 噪声有且仅有 AWGN：本轮 dep2 与 d2_battleB **同一噪声实现**（种子派生
  公式逐字一致 ⇒ 老 checkpoint 的 cert/dep/dera 数字直接 join，另有
  独立重算抽查逐位复核，见 §3 确定性栏）；
- H0 = 纯合成 AWGN（d1 发现2：capture 帧间段强非噪声突发，禁止真实帧间窗）；
- GT 只来自干净信号（cert 模板冻结计分用）；dep2 检测链不使用任何 GT
  量（锚/δ/κ/conj 全部数据驱动或固定格）；
- 同 FAR 精确分位（逐 δ 池化，各臂自己的 H0 池）；
- native 冒烟 28/28（acq 全对、分数 47.8~52.8dB ≫ 门限 ~11.9dB）。

## 2. dep2 设计（m2_core.py）

- **估计集 E** = 前 K_a 个前导 chirp（采集，**无门限**；K_a 自适应
  {8:6, 16:12, 32:12}）：相干列搜索
  T(k,κ)=Σ_j X_j(k)e^{−2πiκ(j−c_e)}（2048 半 bin 列 × κ-FFT 256）→
  DTFT 细化（p0 ±1.25 步 0.25 × κ 256）→ ν̂0（c_e 质心参考）。
  = **前导相干平均锚**（任务 #1）：相干 K_a 行、方差 ÷K_a。
  （δ 不在采集估计：walk 斜率在短基线上被 κ 维完全吸收——实测 native
  δ̂_a 误差 0.03~0.10 ⇒ 采集只出 ν̂0，δ 交确认格网。K_a 取值的预算论证
  见下。）
- **确认集 C** = 其余前导 + 2 sync + 2.25 SFD（K_c = P+4.25−K_a =
  6.25 / 8.25 / 24.25）：
  score = max_{conj(2)×锚bank(±0.25,3)×SFD镜像bank([0.5,3.5],7)×δ固定格(41)×κ(256)}
  |Σ√b_j x_j(p_j)|²/(σ̂²·K_c)。
- **H0 证书（精确）**：锚是 E 的函数且 E∩C=∅ ⇒ 给定锚，C 行谱未条件化
  ⇒ 逐格 Exp(1) 精确；公共移位 ν̂0 不改格间相关（白噪 DTFT 平稳）⇒
  条件 H0 = 无条件 H0。**采集失败只伤 H1 不伤 H0**（拆分的证书本质）。
- 预算（实测标定）：采集噪底 ≈11~12.5（每 chirp 归一，2048 列×κ 瓣的
  Gumbel 最大值，σ≈0.77dB）⇒ acq95 需 K_a·γ·0.94 ≥ 底+2σ；conf95 需
  K_c·γ ≥ 门限×1.62（H1 展宽实测）。P=8 两约束在 K_a=6 交（K_a=7 采集
  +<1dB 而确认 −0.75dB，实测 wash）；P=16/32 前导富裕，K_a=12 使采集在
  −33/−34 达 100%/85%（实测 33/33、28/33）而 K_c=8.25/24.25 仍有
  2~4dB 确认裕度。

## 8. 预注册判定与 M3 交接

**判定：未达"突破"（≥+2.0dB 无漂移 & 全 δ ≥+1.5 & 负局<10% 三项全未达成）；
无漂移 +0.85~+1.25dB（两门限口径）落在"部分（+1~2dB）"下沿；漂移域
+0.3~+0.9（δ≥0.02）未达 +1.5；配对负局率 87.5% 远超 10%。**

失败诊断（结构清楚）：
1. **H0 折扣回收本身成功**（门限 13.7→11.5-12.1dB，+1.6~2.3dB）——拆分
   证书机制按理论工作；
2. 吃掉收益的是**能量转移税**：P=8 的 12.25 场被拆成 6+6.25，确认场
   （6.25）低于 DeRa 自己的 8 ⇒ P=8 组仅 +0.3；采集墙（相干 6/12 行 vs
   2048 列噪声极大值，−34 仅 76%/43%）进一步截断深端；
3. 耦合臂 dep2c 证明另一条路不通：全场能量 +1.5dB H1 但耦合税 +1.5dB
   门限，净负（−0.6~−1.6）。
4. 无 θ 的类型失配：确认和相干度仅 ~60-88%（native 全场缺口 −2.5dB），
   δ̂ 伪峰（§5）与其同源。
