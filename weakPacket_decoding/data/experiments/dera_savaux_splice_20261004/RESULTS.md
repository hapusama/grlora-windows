# dera_savaux_splice_20261004 — 拼接战：DeRa 前端 × Savaux 解调器

日期：2026-10-04。脚本 `splice_runner.py`（7 链，532 单元，4087s，6 workers，
断点续跑）；逐帧归因 `debug_f00.py` / `debug_delay.py`。

用户指令：实验 B（先验给定）下 Savaux 相干合并深端最强，验证
**DeRa 前端能否完全激发 Savaux 完整解码链条的潜力**，多组真实 bin 数据
实验观察。

## 0. 结论速览

1. **原样拼接不能激发**：DERA×SAVAUX 中段 PER 比其参照差 2~3 倍——
   −17 .333 / −20 .452 / −22 .571，同帧全先验参照（PRIOR×SAVAUX）仅
   .119 / .131 / .250；也全面差于 DERA×TRIMMER（.262/.369/.476）与
   DERA×DERA（.000/.024/.107）。native 即已劣化（SER .123 vs .039）。
2. **缺口不在 CFO，在亚样本定时项**：DERA 前端 f̂ 误差中位数全档
   ≤0.004 bin、hs 误差 0 样本，但缺 −sto_frac·OS（±1.9 样本）补偿。
   该残差使 Savaux 合并谱峰落到 bin 边界 → **argmax 逐符号混跳**
   （diff 呈 {0,−1} 混合，非单一 δ 可修）——这是它伤 Savaux 而不伤
   TREL/DERA（κ 原生处理）、轻伤 Trimmer 的机制。
3. **一行可部署修复基本兑现潜力**：DERAfd×SAVAUX（前导 4 符号 dechirp
   峰能量对时延网格 [−2,+2] 步 0.25 取 argmax，无 GT）native .000/.000，
   −17 .012/.012、−20 .027/**.024**、−22 .075/**.107**、−24 .404/**.583**、
   −26 .655/1.0。**−20/−22/−24 PER 追平全 DeRa（.024/.107；−24 差
   3/84 包 .583 vs .619，噪声量级）**，全档碾压原样拼接与
   DERA×TRIMMER/×TREL-5 的同档 PER。−17（.012 vs 全 DeRa .000）与
   −26（.655 vs .521）仍小输。
4. **"−28 dB" 不成立**：−28 档 DERA 前端同步率 0.00（全链 PER 1.0）；
   全先验参照 SAVAUX 亦 SER .719/PER 1.0——真实 OTA + 本协议口径下
   Savaux 的下限在 −26 附近（PER 1.0），−24 起即明显退化（参照
   .234/.595）。
5. **附带发现**：fd 修复臂 SER/PER 全档优于"真实参数"参照
   （PRIOR×SAVAUX，−20 .027/.024 vs .072/.131）——CSV 生产先验
   （sto_frac/cfo_frac 冻结值）对 Savaux 并非最优工作点；PRIOR 臂是
   诊断参照而非上界（与主方案 C 臂声明一致）。

## 5. 机制归因（debug_f00 / debug_delay，native 逐帧）

1. 坏帧（DERA×SAVAUX raw SER .2~.5 的 10/28 帧）上 cand0 的 f̂ 误差
   ≤0.005 bin、hs 误差 0——频率/整样本定时均无责。
2. 行谱 diff 分布呈 **{0, −1} 混合**（如 f00 {0:14, 1023:21}、
   f19 {0:17, 1023:18}）：部分符号 argmax 落 v+1、部分落 v——任何单一
   δ 都修不回，这是 raw SER 直接进 SER/PER 判据的原因。参照：干净帧
   （f02/f05/f14/f17）diff 为**常数** {0:35} 或 {1023:35}，δ 一卷即净。
3. 补 −sto_frac·OS（PRIOR 同款时延）后，坏帧全部恢复常数映射或全对
   （f01/f13/f19/f00 验证）；干净帧加同时延不变坏（对抗测试通过）。
4. f00 时延细扫（步 0.125，[−1.5,+1.5]）呈**双平台**：
   d ≤ −0.625 全对（SER 0）；d ≥ +0.375 恒定 −1（δ 可修）；
   仅中间 ~0.6~0.9 样本混跳区致命。时延响应面平坦 → 能量 argmax 落在
   任一平台即净（DERAfd 的 17 点网格全部落在平台，7/7 坏帧 raw SER
   0.000）。
5. 机理陈述：DeRa 前端不补亚样本定时 → Savaux 合并谱峰位置落在
   bin 边界附近 → 逐符号混跳；TREL/DERA 解调器以 κ 格原生吸收同类
   残差（.000 不受影响）、Trimmer 部分吸收（.056），Savaux 相干分支
   合并无此自由度故最伤。

## 8. δ 记账勘误（2026-10-05 补，`debug_gap.py`/gap2.log）

本表 SER 为实验A式记账（δ 逐链 CRC 仲裁，全失败回退 δ=0），与实验 B
（δ 干净冻结）**不可直接互比**。A/B 归因（同噪声段、同先验）：

| 记账 @−26 | SER | 说明 |
|---|---|---|
| A：CRC 仲裁回退 δ=0（本表） | .511 | 复现 checkpoint .511 ✓ |
| B：逐帧冻结 δ_clean | **.425** | ≈ 实验 B 存档 .421 ✓ |
| C：battle 窗口+冻结 δ | .436 | 窗口贡献 ~.01 |
| D：battle 窗口+20260929 种子 | .436 | 种子贡献 ~.00 |

缺口全由 6 个 δ_clean=1 的帧贡献（深端 CRC 全失败 → 回退 δ=0 → 整帧
35 符号全记错；冻结 δ 下同帧 err 27~68）：+254/2940 = +0.086。
**物理上 Savaux 未变差；记账对齐后 .425 vs .421 逐位级吻合。**
同记账横比（实验 B 表）：DERA 解码器 −26 SER .338 < SAVAUX .421
——"Savaux 深端弱于 DERA 解码器"为真实物理差（两段窗重组+ML 公共相位
vs 逐符号硬 argmax），与本勘误正交。

口径勘误同步：(a) "Savaux 0.8 正确率@−26" 出自 **SF11 LDRO** 战表
（SER .156 = 84.4%，2048-chip + 4-bin 值格），SF10 非 LDRO 同位为 ~58%；
(b) "能干到 −28dB" 出自 litenap_savaux_clean_gt_20260724（high_snr 捕获、
added-SNR 口径、17 clean 包）——该实验**测到** −28 但 Savaux 在彼处
SER=60.02%，−28 从来不是工作点；(c) Savaux 论文（TechRxiv 16657063
= IJMNDI'22 版，2026-10-05 用户提供 PDF，`paper/Savaux_TechRxiv16657063.pdf`）
Eq.(2) 模型零 CFO/STO/SFO、明文 "We assume a synchronized reception"、
sync mismatch 列为 future work；其 3dB 声明 = OSR2 vs OSR1 过采样相干
合并增益（仿真 SF7/8/9，AWGN+Rayleigh，无 OTA）——**本实验恰好实测了
该论文未做的"非理想接收"半场**。
