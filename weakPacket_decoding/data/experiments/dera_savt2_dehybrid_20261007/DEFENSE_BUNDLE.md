# 防御实验包（2026-10-07，红队二轮关键项的当日实测）

三个小实验，全部用现有数据，对应红队二轮"一周内最便宜且最能堵嘴的

## D1. 复杂度基准（bench.log，B1）

native wall-time（Python 原型，单帧 pre8，35 payload 符号）：
| 组件 | 耗时 |
|---|---|
| DeRa 检测（dera_sync） | 1.04–1.79 s |
| DeRa 解码（DERA_DEC） | 0.07–0.08 s |
| Savaux 裸解调 | 0.014 s |
| SAVT 整包网格（17 态） | 0.74–0.85 s |
| SAVT2 双层网格（35 态） | 1.63–1.80 s |

要点：**SAVT2 网格开销 ≈ DeRa 检测开销同量级；全链 ~2.5× DeRa**
（非红队预估的 10-30×——检测占大头）。对 DeRa 原文 RPi4B 实时预算
（8.192ms/符号，用 4.525ms）：SAVT2 折算 ~49ms/符号（Python 口径）
超预算 ~6×——部署故事需 capture-then-process 网关或 C/FFTW 优化
（35 假设共享高分辨率 FFT 的理论加速 ~35×，未实现）。

## D3. 空信道虚警审计（fa_audit.log）

3 capture 帧间静默段，272 个与帧段同长的纯噪声窗灌全链
（DeRa 检测 pre=8 → SAVT2 → δ CRC 仲裁）：

| capture | gaps | 噪声窗 | FA-detect | FA-decode |
|---|---|---|---|---|
| 8 | 11 | 107 | 0 | 0 |
| 16 | 12 | 86 | 0 | 0 |
| 32 | 8 | 79 | 1 | 0 |
| **总** | | **272** | **1 (3.7e-3/窗)** | **0 (0/272)** |

**35 候选 × 5δ 的多重比较在纯噪声上零幻影整包**——CRC 多重比较攻击
被数据卸掉；检测级 FA 亦仅 1/272。

## D4. 消融：同格去 Viterbi（ablate.log，TMC 审稿人点名项）

GRID-IND = 同 35 态网格、逐符号独立 argmax（无转移约束）：

| 条件 | GRID-IND | SAVT2（Viterbi） |
|---|---|---|
| native | **11/28 坏帧** | 0/28 |
| −22 | PER .795 / SER .177 | .048 / .006 |
| −24 | PER .942 / SER .227 | .262 / .044 |

**决定性**：逐符号独立决策在同格上灾难性崩溃（native 11/28 = 逐符号
argmax 被 35 态 max 的选择性噪声带偏），序列级转移约束就是贡献本体——
"序列决策 vs 逐符号决策"的类别证据补齐（TMC 命题 B 的实验面）。
