# dera_savt_20261005 — v4：整包时延网格（D2F 网格思想 → Savaux 对齐）

用户指令（2026-10-05）："用 D2F 的网格思想给 Savaux 做对齐，先整包的，
效果一般再算偏移副本各自网格"。脚本 `splice_dera_savaux/code/
splice_v4_runner.py`（4 臂，448 单元，790s）。**整包版即强，v4-b（偏移
副本各自网格）备案未启用。**

## 0. 方法

整包时延网格（DERA×SAVT）：对 DeRa 前端 bare 候选段（无 fd、无前导
依赖）建 17 态时延格 D=[−2,+2]×0.25；逐符号发射 = Savaux 合并谱峰功率
（对齐好→峰集中；混跳区→峰跨 bin 分裂掉 2-3dB）；转移 = |Δd|≤1 步
（SFO 漂移模型）+ 0.4 步罚；Viterbi 输出逐符号时延轨迹，每符号取该态
合并谱行 → δ CRC 仲裁（与其余链同一原语）。**对齐决策的证据全部来自
payload 全体符号**——主方案第 3 步（payload 参与选择+成本控制）在时延
轴上的首次完整落地。

## 3. 判读（战绩口径：混血臂，DeRa 前端 port + 我方对齐层 + Savaux 解调器）

1. **DERA×SAVT = 全项目最强链：native~−26 每档 SER+PER 双胜全 DeRa**。
   此前所有版本均有输档：v3 冠军 DERAfdc×GAMMA 输 −24 SER（.303 vs
   .150）；DERAfdc×SAVAUX 输 −24/−26 SER。SAVT 把 −24 SER 翻成
   **.101 vs .150**、−26 SER **.441 vs .521**，PER −24 **.310 vs .619**
   （26:52 包）、−26 .988 vs 1.000。
2. **网格完全取代 fd_c**：SAVT 不用前导、不用 fd_c，裸候选直接走格，
   全档优于 DERAfdc×SAVAUX（−24 SER .101 vs .364，3.6×）。归因：
   fd_c 的对齐证据只有前导 8 符号且整包静态；网格用全部 35 个 payload
   符号的发射证据 + 漂移约束，逐符号自适应。
3. 超越 v3 冠军 γ-链：−24 .101/.310 vs .303/.440。机制：γ-链仍吃
   fd_c 的静态时延（深端选错平台伤它），网格没有这个依赖。
4. 统计诚实声明：SER（千级判决/档）显著；PER −24 档 26:52 显著；
   −20 档 0:2、−22 档 4:9 方向一致但样本小；数据仍为 3 capture 伪
   重复结构（评审会审已裁定报告体系须 SER 主指标）。
5. 未调参声明：网格步罚 0.4 为首试值未扫；v4-b（偏移副本各自网格，
   粗副本×细格两层结构）备案，若深端仍有残余可启用。
