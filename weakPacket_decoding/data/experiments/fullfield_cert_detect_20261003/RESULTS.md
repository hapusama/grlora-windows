## 0. 结论速览

1. **全场相干 oracle 界（FF_tmpl）在真实 OTA 深端裕度 +4.2~+5.6dB over
   DeRa 式 A_P**（P=8 组 −32dB：+7.2 vs +1.8 dB 裕度，Pd 1.00 vs 0.83；
   P=16 −32：+8.9 vs +5.0；P=32 −32：+12.0 vs +7.8）——远超
   10log10(12.25/8)=1.85dB 的能量算术。分解 ≈ +1.85 场能量 +
   **+2.7 固定统计量门限红利（Pfa=1e-2 下 TMPL 门限 8.56dB vs 搜索族
   11.3~12.5dB）** + ~1dB 搜索族 H0 噪声代价。**证书不是锦上添花，
   是门限红利本体。**
2. **可部署固定搜索族收获不了**：FF_lin/FF_up 深端反低于 A_P
   （P=16 −32：+3.9 vs +5.0），FF_ml（类型偏移边缘化）追回部分
   （P=8 −32：+2.5 vs A_P +1.8；P=16/32 持平）。瓶颈 = **chirp 类型
   切换处的确定性相位跳变（实测 ~135°/230°）+ 非 preamble 列分数 bin
   相位**——线性/二次剪切均吸收不了（FF_q≈FF_lin，二次项仅值
   0.3~0.5dB@native）。收获该增益的可行形态 = **模型模板化相干合并**
   （DeRa Eqs.10-11 预测相位 + (f̂,κ) 结构化网格），其 H0 代价可推导
   ——这正是第二篇检测器的设计问题，本轮给了定量目标。
3. **漂移在默认帧上确证次要**：帧级走动中位 −0.0061 bin/符
   （26/28 负向，与 A3 实测同分布）；P=32 前导二次相位弧 ~160° 仅值
   native +0.5dB。keystone/剪切的真实战场仍是 E2（induced-SFO），
   Q1 结论（漂移支柱移出默认帧）第三次独立确认。
4. **CFAR 性实证**：自归一统计量（÷K·σ̂²）分档门限在工作段
   （−22~−32dB）极差 ≤0.7dB；全程（−10~−32，22dB 噪声范围）极差
   2.9~4.2dB（−10 档偏高 = H0 窗邻包泄漏残余，见偏差 §5）。
   FF_tmpl H0 均值 1.71dB ≈ 中位数偏差理论值 1.44dB ✓ 高斯稳定。

## 5. 偏差声明

1. **机制级（实验B-检测型）**：窗口 GT 锚定、无扫描/locate——变体间
   可比；不可与 port 系统门限（DERA 同步 −25.3dB）直接比（锚定省掉
   扫描损失，A_P 在 −26 仍 Pd=1.00 即此）。系统级集成 = 后续 E3 型。
2. FF_tmpl 为 oracle（干净相位）；可部署形态（模型模板 + (f̂,κ) 网格）
   未实现——本轮交付的是界与瓶颈定位，非最终检测器。
3. SFD 0.25 部分符号未计入（K_tot=P+4）；记账差 10log10(4.25/4)
   ≈0.26dB，恒定不改变排序。
4. native 档 H0 存在邻包污染（中位 ~10dB ≫ 理论 1.6dB）→ 门限校准
   只用噪声主导档（−10..−32）；−10 档偏高亦为残余污染。
5. frame17 前导 tone 骑 ±B/2 卷绕边界：walk 诊断 (+22.2) 失效，
   分数不受影响（各档正常）。
6. σ̂² 用远列中位数（指数分布中位数 = 均值×ln2）→ 全变体统一
   +1.6dB 系统性偏置，门限校准经验化吸收，不影响变体间差。
7. 每 capture 内 H0 窗按 live 功率过滤死区（捕获 >50% 零填充）。

## 8. ff2 轮：可部署收获器（全局偏移模型 + 两段式自校准）

变体：FF_se（κ̂ 从带噪前导 FFT 峰，pre/sync/down 三段在 κ̂ 内部
相干后幅度相加 = 类型偏移 ML，down 双共轭取大，无 max 搜索）；
FF_se_ok（同上但 κ 用干净前导——半 oracle，消融）；A_P/FF_tmpl
同单元重算。5133 记录，同协议。

**结果（裕度 = 中位 H1 − 分档门限）：**

| 组 | 档 | A_P | FF_se（可部署） | FF_se_ok（κ已知） | FF_tmpl（oracle） |
|---|---|---|---|---|---|
| P=8 | −26 | +7.9 | +8.0 | **+9.4** | +13.5 |
| P=16 | −26 | +10.3 | +10.0 | **+11.5** | +15.1 |
| P=32 | −26 | +13.5 | +12.8 | **+14.3** | +17.7 |

H0 池化均值：A_P 8.89 / FF_se 10.04 / FF_se_ok **5.19** / FF_tmpl 1.71 dB。

**三条定论：**

1. **全局常数类型偏移模型失败**：r_sync 圆 std 74.4°、r_dn 圆方差
   2.28 rad²（14 帧校准集）。来源=列切换伪影（整数列 argmax 在亚 bin
   走动下跳变 180°）+ 漂移二次项 + κ_true 估计量化。类型偏移不是
   跨帧常数，基于它的 FF_cal/模型模板路径（§7.1）需要先解决列跟踪
   与亚网格 κ——负结果入库。
2. **κ 独立已知时两段式收获成立**：FF_se_ok 对 A_P = +1.5(P=8)/
   +1.2(P=16)/+0.8(P=32) dB ≈ 理论 10log10((P+4)/P)，且门限低
   ~1dB（确认段无搜索）。**κ̂ 自耦合是收获杀手**：FF_se（同实现
   估计 κ̂）的 H0 被抬 +4.9dB（argmax 选择偏置经由 F_pre 渗入确认
   段），裕度回落到 A_P 持平。结构性结论：**确认统计量的紧致 H0
   要求滋扰估计与求和样本解耦；单发单收同窗内不可得**——两段式
   换解耦（前导估 κ̂、sync/down 确认）只强化虚警证书，不增检测
   裕度（确认段仅 4 chirp，弱于前导段）。
3. **对"能否超过 DeRa"的裁定**（机制级、GT 锚定口径）：上界真实
   （+4.2~5.6dB）；可部署单统计量收获 = 0~+1.5dB，取决于 κ 的独立
   已知程度；系统级超越不在此统计量——在证书层（两段式 FA 优势）、
   漂移域（E2 后 DeRa 前端散焦真空）与主线解码器。全场积分在论文
   中的定位：P=8 默认帧的 +1.76dB 能量上界 + 收获结构性困难的
   定量证据，作第二篇动机/消融，不单独成章。

偏差声明追加：FF_se_ok 的 κ 来自干净信号（半 oracle，仅作消融）；
FF_se 的 down 双共轭取大引入 1 个额外比较维度（H0 影响 <0.1dB，
H0 校准已含）；κ_true 量化网格 1/256 cyc/sym（校准诊断的下界因素）。

## 9. ff3–ff6 轮：认证确认检测器——机制级超越 DeRa 式统计量

四轮递进（同 harness、同真实 .bin 数据、同协议；checkpoint_ff3/4/5/6）：

**ff3（拆分 + 耦合税定律）**：帧内数据拆分（前 K_e=4 前导估 κ̂、确认集
=其余前导+sync+SFD）使确认统计量的权重与求和样本独立 → 条件高斯论证
给出 H0=精确指数。实测：FF_split_model 分位比 q90/q99=0.506（理论
0.500）vs A_P 0.659；门限 7.5 vs 10.8dB（**+3.3dB 证书红利**）。同时
坐实耦合税：同窗估计的 FF_se（ff2）H0 抬 +4.9dB——**est-then-sum 的
H0 由"权重与样本是否独立"唯一决定**（新定律，含 3 行证明）。
κ̂ 自耦合杀手确认：可部署 FF_se 与 A_P 持平。

**ff4（bank 设计规则）**：确认统计量在 κ̂ 中心定宽 bank（b=1/9/25）
取 max——H0 仍解析（max-of-b 相关指数族，q-ratio 0.506/0.508/0.557
单调），门限 7.5→8.3→8.9dB；κ̂ 误差分布实测（|Δ|p50: 1.5@−10 →
10.3@−32 bin，p90: 3.6→46.3）= 设计曲线：目标 Pd ↔ 最小 b。

**ff5（段常数锚不足）**：全场 GLRT-max + 段常数类型锚（r_syn/r_dn）
≈ A_P（−0.5~−1.3dB）——sync 对内两 chirp 的 c 不同 → 逐 chirp 模型项
不同，段均值对不齐。**逐 chirr 相位 = 必要模型**；其组成 = 斜率 ramp
+ 分数 bin ψ（Dirichlet 相位律 arg X[k*]=πδ，探针 0.9422 vs π·0.3=
0.9425 精确验证；幅度域可估 → 圆对称引理保 H0）+ c 相关项（DeRa
Eqs.20-21 的检测级搬运，sync/down 的 c 协议已知）。

bank9）+ 确认集 {后半前导+sync+SFD, 8 chirp} 逐 chirr 相位锚（干净域
