## 1. induced-SFO 实现与自校验（d2_core.resample_sfo，d2_probe_sfo.json）
- **实现**：y[m]=x(origin+(m−origin)(1+ε))，ε=δ/N，origin=场首窗。
- **δ 映射自校验（P3b，扣 native 后净读回，28 帧×5 档）**：目标
  {0.005,0.01,0.02,0.04,0.082} → 读回 {0.0050,0.0100,0.0200,0.0405,0.0819}，
  **max|err|=0.004 ≤ 0.005 ✓**；
- **零损伤控制组**：ε=0 逐位恒等；cert-q 无噪聚焦分数 55.0/…/54.9 dB
  五档平坦（P5）✓；
- **物理发现 A（本轮最重要）**：时钟 SFO（重采样）**无跨符相位二次项**
  （净 c2 ≤ 0.024 rad/idx² ≈ 噪声级；πδ·idx² 律属去斜域频率斜坡模型，
  重采样推导二次系数 πδ²/N→0）⇒ 定律5 闭式须分损伤模型域（§2 裁决）；
- **物理发现 B（解码端）**：理想栅格重启窗下 payload 的**整数 bin 走动
  被窗时漂移近似抵消**（naive 频率走动注入的合成帧 am−v 每 1/δ 符步进；
  重采样注入的 OTA 实测 δ=0.082 全 payload 只走 ~0.3 bin）——γ 序列斜率
  −δ 反映的是 V1/V2 分裂效应而非整数 bin 位移；合成校准 y=−κ_rel−0.25。
- cert 模板升级 cert-q（前导相位二次拟合）防残余 c2 损失。

## 4. 总裁决（两仗合并）
- **检测级（Battle B，同表结论）**：机制级（cert，GT 锚定冻结变换+闭式
  CFAR）**战胜 DeRa**：无漂移 +3.5dB、δ=0.082 **+4.16dB**、全 δ 平坦，
  配对 805W/2L——第一仗结论在漂移域保持并扩大。可部署级（dep：非相干
  keystone 粗捕获锚+δ 网格+κ-FFT，无 θ）Pd=0.9 与 DeRa 持平到 +0.6dB
  （δ=0.082 +0.62dB）——**检测可部署臂未形成 dB 级优势**（折扣=H0 门限
  13.7 vs 10.6dB 的搜索+选列膨胀 ~3dB，见 §5）。
- **端到端（Battle C）**：**未战胜**。δ=0 DeRa 全链领先 ~1.9dB（10%PER
  −22.1 vs 我方 −20.2；与我方 cert 链差 0.5dB）——与 front battle 已知
  排序一致（DERA 解码器优于 TREL-5 ~1-2dB@真实同步），非本轮回归；
  δ=0.02 DeRa 再领先 ≥1.5dB（其 f̂/locate 对中带漂移稳健）；δ=0.082
  双方全崩（DeRa：γ 旋转+散焦+常数 δ 仲裁三重失效；我方：锚旋转质量
  +残余 0.3bin 走动翻转）。
- **折扣结构**：我方 E2E 的缺口不在检测（Battle B cert +4.16dB）而在
  ① 解码器底座（TREL-5 vs DERA demod −1~2dB，已知）；② 部署锚的频旋
  质量（dep ν̂0 ±0.2-0.3bin + 对齐 ±4 样本残余 → δ=0.02 时 −20dB 档
  PER 从 native .18 恶化到 .77，而 DeRa 的成熟 locate/f̂ 链不受影响）；
  ③ 漂移解码端未完成（γ-链走动反映射的整数域/π 奇偶/初值分支三关，
  本轮调试中定位并部分修复，最终锁定 TREL+零走动的保守版）。
- 结论一句话：**机制级检测战两战全胜（+4dB 级、漂移免疫、证书可证）；
  可部署检测臂打平略胜；端到端在漂移域负于 DeRa 全链（≥1.5dB 量级），
  缺口在解码底座与部署锚质量，不在检测机制。**

## 5. 遗留风险与部署路径
1. **dep 的 CFAR 折扣（~3dB）**：两锚选列 + 41×256 格搜索的 H0 膨胀。
   部署路径：(a) 锚估计从"非相干 bank"升到"极化相干 bank"（用 κ̂ 先验
   把 41×256 缩到局部）；(b) 2D 上穿闭式（需 2D 相关半径解析）替代 MC；
   (c) 本轮 2D 膨胀闭式差距已标定（+1.11dB@1e-2）。
2. **γ-链在真实漂移下的三个新发现（本轮实测，产线 gamma_link 需吸收）**：
   y 斜率=−δ_bin（符号）；y=−κ_rel−0.25（几何常数）；WLS 合角初始化在
   δ·span>1 圈时落平坦分支（需 δ̂ 先验+阶梯）。三者漂移前不可见。
3. **理想栅格重启窗的整数走动抵消**（发现 B）：把"逐符整数走动反映射"
   从必需降级为 ~0.3bin 边界翻转修补——δ=0.082 双链全崩的主因是分数
   域（γ 旋转 / 锚质量），不是整数走动。修复优先级：锚质量的方差压缩
   （前导相干平均锚）> γ 相位补偿的奇偶稳定化 > 走动修补。
4. **DeRa port 剩余不活跃机制**：其 §3 复合畸变补偿在 80ppm（本轮 ε）
   下已被声明为活跃但未 port——若其论文补偿含逐符频率跟踪，δ=0.02/0.082
   的 DeRa 战表可能更强（本轮数字是 port 下界）。反向声明：其解码器
   Stage-2 单 φ̂0 无逐符跟踪、δ 仲裁为常数集——port 语义忠实。
5. dep_dhat（dep 的 δ̂ 网格读数）在 native 也偏 ±0.08（无 θ 时 sync/SFD
   相位意外对齐的伪峰）——作为先验时用 |δ̂|<0.2 门 + γ 拟合 σ² 择优兜底
   （已实现）；根治需 θ-free 的 δ 峰值鉴别（后续）。
