# Sionna RT Experiment Artifacts

This directory contains the outputs from the aligned SF10 LoRa SER study. The
code and full reproduction commands are in `weak_decoder/rt_sim/README.md`.

## Directory Layout

- `final/aligned_ser_final_487p7`: authoritative combined run at 487.7 MHz.
- `diagnostics/aligned_ser_ablation_487p7`: interference-only companion run.
- `diagnostics/aligned_ser_thermal_487p7`: thermal-only companion run.
- `archive/aligned_ser_main`: earlier power range before final calibration.
- `archive/aligned_ser_ablation`: earlier interference-only run.
- `archive/aligned_ser_v1`: initial multi-condition experiment.
- `archive/smoke` and `archive/smoke_cg`: small pipeline and CG checks.

No historical run was deleted. `final` is the result to cite; `diagnostics` and
`archive` are retained for traceability, not for combining into extra samples.
The workspace base commit was `b957858`; the RT code was an uncommitted local
addition, so `code_provenance.csv` records hashes of the exact code snapshot.

## Files In Each Run

- `metadata.json`: command arguments, CIR metadata, pattern names, receiver and
  interference models, alignment assumptions, and target-response diagnostics.
- `summary.csv`: one row per scenario and target-power point, aggregated over
  trials.
- `aggregate_summary.csv`: detector totals for thermal-only, interference, and
  all scenarios. This file is present in the final run and is now generated by
  the runner for future runs.
- `trial_metrics.csv`: one row per scenario, target-power point, and trial.
- `symbol_metrics.csv`: ground truth and every detector decision per symbol.
- `ser.png`: SER curves against measured target SINR.

## Authoritative Result

The final run contains 5,400 aligned symbols: 1,800 thermal-only symbols and
3,600 symbols with one or two asynchronous same-SF LoRa interferers.

For the interference subset:

| Detector | Errors | SER |
| --- | ---: | ---: |
| Savaux | 1729 / 3600 | 0.4803 |
| Equal 8 patterns | 1741 / 3600 | 0.4836 |
| Equal 8 + wrap | 1511 / 3600 | 0.4197 |
| Direct GLS | 1735 / 3600 | 0.4819 |
| CG GLS | 1733 / 3600 | 0.4814 |
| CG GLS + wrap | 1500 / 3600 | 0.4167 |
| Conditional GLS | 1554 / 3600 | 0.4317 |

For thermal-only symbols, Savaux records 93 / 1800 errors (SER 0.0517) and CG
GLS + wrap records 105 / 1800 (SER 0.0583). The current evidence therefore
attributes most of the interference-case improvement to wrap consistency, not
to covariance weighting.

## Interpretation Boundary

Sionna RT supplies deterministic propagation paths. Receiver noise is generated
by the SER runner as complex thermal noise with `k*T*BW*NF` power and is passed
through the shared receiver FIR. These artifacts do not measure environmental
or receiver-generated colored noise and do not replace an independent hardware
SER experiment.
