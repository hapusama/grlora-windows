## 附注 1：temp_utf8.txt 原始内容（SX1276 接收长度限制）

部分工程出现"下行 64 字节限制"，原因是 `sx1276-board.h` 中
`{ MODEM_LORA, REG_LR_PAYLOADMAXLENGTH, 0x40 }`；正确工程已设为 `0xFF`。
实测：接收方配 0x40 时只能收 ≤64 字节的包；**该寄存器只限制接收方**，
发送方无论配何值、发多长都能完整发出。后续对接硬件收发时需复核此项。

## 附注 2：被删 H7 通用版 README 全文

> # LoraSTMacH7 STM32H743VIT6 port
>
> This is an independent STM32H743VIT6 port of the legacy LoraSTMacL1 project.
> It does not modify the original STM32L152 workspace project.
>
> ## Purpose
> - Verify that the STM32H743 toolchain configuration builds correctly.
> - Verify SWD connection and internal Flash programming before porting LoRa.
> - Provide the correct Cortex-M7 startup, device headers, and memory map.
>
> ## Build and download
> 1. Open `MDK-ARM/LoraSTMacH7.uvprojx` in Keil uVision. 2. Build with `F7`.
> 3. Debug 选 ST-Link + SW；Utilities 选 ST-Link。
> 4. 确认 Flash 算法为 2MB STM32H7 内部 Flash @0x08000000。5. F8 下载。
> 程序故意不驱动 LED（当时板卡引脚未定）；调试时 `g_heartbeat` 应持续自增。
>
> ## Porting boundary
> LoRaWAN 协议代码可后续从 L152 工程迁移，但 clock/GPIO/SPI/UART/RTC/
> 中断/低功耗/SX1276 board 文件必须按实际 H743 引脚实现。
> CMSIS 许可证保留于 THIRD_PARTY_LICENSES/。
