## 1. 核心命题（一句话）

**反转 sync 问题的优化方向**：不是"sync 能做多准"，而是"decoding 容忍多不准"。
给定 decoding 目标（如 10% SER @ SNR*），sync 存在**最小充分配置**（前导长度 L、
估计精度 σ_ν/σ_τ/σ_φ/σ_κ）；超过该配置的 sync 投入是纯开销（能量/时延/复杂度）。
由此导出 **SNR 自适应 sync 策略**：高 SNR 域残差被噪声边际淹没→粗 sync 即可；
低 SNR 域每 dB 都要命→精细 sync。切换点可闭式预测。

与主论文叙事的关系：这是 **Decode-to-Finish-Synchronization 的量化核心**——
"做到 decoding 能 finish 为止"从口号变成可定价的边界函数。不换脊柱，补理论心脏。

  - DTS 叙事定型 = **架构×sync 精度联合设计**（容忍度不对称 + 最小充分

## 3. 理论原料（全部已有，零新机制要发明）

| 已有资产 | 在 DTS 中的角色 |
|---|---|
| 耦合税定律（权重与求和样本独立⇔H0固定族） | "过度 sync 有税"的机制级证明 |
| Dirichlet 列走动定律（SFO 真实 −0.33dB @P=8 vs naive −3.45~−15dB） | 社区对 SFO 过度补偿的直接证据（定律5修正版） |
| γ_i=πκ_i 盲差分恒等式 | 残差可被 decoding 端 marginalize 的解析工具 |
| DeRa 两段窗（§3.3/§4.3） | 残差 CFO→wrap 两段→能量损失的先例模型（但 DeRa 是固定策略，非自适应） |
| 前导折叠 12.25/8≈1.8dB 观察 | sync 长度↔能量增益的实测锚点 |
| dep4 两级检测（粗+精） | SNR/置信度自适应 sync 的现成骨架 |
| E3-lite 裁定（对齐精度=最后一公里, ±0.2-0.3 bin） | 容忍度曲线要解释的实测缺口 |
| ff2 教训（κ̂ 自耦合吃光 +0.8~1.5dB 红利） | "补偿不一定赢"的反例证据 |

**可发表断言候选**（每条须过真实管线+DeRa 同表，铁律不豁免）：
1. LoRa sync 残差→demod SNR 损失的实测传递函数（分轴：ν_frac/τ/φ/κ），与
   两段窗/Dirichlet 理论预测逐轴对账。
2. **容忍度不对称命题**：marginalize-soft 链（TREL/BCJR）对 κ/相位残差的容忍
   宽于 est-compensate 链（DERA/TRIMMER）——族2 机制分叉的直接实验证据。
3. 最小充分 sync 配置表：每档 SNR × 每轴残差的"可忽略阈值"，以及前导长度
   的等效交换曲线（L=8→6→4→2 的 decoding 边界移动）。
4. SNR 自适应 sync 策略 + 闭式切换点 + 与固定策略的同表对比（净增益 dB 或
   等效开销节省）。

## 4. 实验计划（EXPERIMENT_PROTOCOL v1.1 框架内）

### DTS-1：残差容忍度曲线（第一刀，本日启动）
- **类型**：实验C 族（注入型，§5A.4 规则）：研究对象=sync 残差本身，非解调器
  排序。所有链吃**同一份**注入残差（公平输入铁律不破）；噪声仍整包 AWGN。
- **定位声明**（RESULTS 必写）：残差注入=数字域受控实验C，非 OTA 原生工况；
  原生残差分布用 A3 实测（δ 0.002~0.024 bin/符）标定压力档。
- **设计**：SF10 28 帧起步。基线=实验B 冻结先验；在冻结先验上叠加受控残差
  ε∈轴×档位；SNR 档：native + −20（工作区）起步，扩展 −18/−22。
  轴与档：
  - ν_frac（分数 CFO 残差）：0, ±0.05, ±0.1, ±0.2, ±0.3, ±0.5 bin
  - τ（亚 chip STO 残差）：0, ±1/8, ±1/4, ±3/8, ±1/2 OS
  - φ（相位残差）：0°, 15°, 30°, 45°（全体符号共相位）
  - κ（逐符号漂移残差）：0, ±0.005, ±0.01, ±0.02 bin/符（对齐 A3 实测界）
- **链集**：PLAIN / TREL-5 / TRIMMER / DERA（下游判据固定；解调器排序不是
  本实验目的，链间差异只用于容忍度不对称命题 2）。
- **产出**：SER(ε) 容忍度曲线族 → dB 等价损失(ε) 传递函数 → 可忽略阈值表。
- **冒烟标准**：ε=0 各臂 ≈实验B 历史值（TREL native SER=0）；负控：ε=0.5 bin
  必须显著劣化（注入有效性检查）。

### DTS-2：前导长度交换曲线（第二刀，待 DTS-1 定阈值后）
- OTA 前导截断（L=8→6→4→2，从现有 8/16/32 capture 的 sync_chain 产物截取），
  测 sync 成功率×SER 联合边界 vs L；与 DTS-1 阈值表对账（预测：短前导损失
  主要走 ν̂/τ̂ 精度轴，量级可由阈值表预测）。

### DTS-3：SNR 自适应策略同表战（第三刀）
- 策略 = 按 SNR 档切换 sync 精度（dep4 两级骨架：高 SNR 粗档/低 SNR 精档），
  对固定精度 sync 与 DeRa 前端同表（实验A 形态，§5A.1 判据=下游 PER/SER）。

## 5. 风险与红线

- **红线**（继承 taxonomy 教训）：不写"没人分析过误差"；写"逐误差解调级分析
  已有（UniChirp/补偿线），由 decoding 边界反推最小 sync + SNR 自适应策略是
  结构性空白"。
- 注入型实验全程按 §5A.4 标注（残差注入声明/压力档标注/负控）。
- "压缩 sync"若动到 TX 侧（改前导长度发射），需新 OTA 采集；先用 RX 侧截断
  回答（DTS-2 的截断版是合法近似，需声明）。
- E2E 未胜 DeRa 的现状不变：DTS 不改解码底座，但它把"sync 投入"变成可议价
  的量——若容忍度不对称命题成立，我方链在粗 sync 下相对优势放大，等于在
  "sync 开销"维度打 DeRa 的固定补偿架构。
