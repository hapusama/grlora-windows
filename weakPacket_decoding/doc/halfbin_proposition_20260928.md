# 半 bin 不可分命题——形式陈述与证明（2026-09-28）

## 模型

去斜后的单个 LoRa 符号观测
$$y[n] = A e^{j\phi}\, e^{j2\pi (s+\kappa)n/N} + w[n],\quad n=0,\dots,N-1,$$
$s\in\mathbb{Z}_N$ 为符号值，滋扰 $\kappa\in[-\tfrac12,\tfrac12)$ 为统一分数偏移
（分数 CFO/STO/SFO 漂移/子 bin 时延的塌缩），$A e^{j\phi}$ 未知复增益，
$w$ 为任意循环对称噪声（**分布不需高斯**）。记 $\mathbb{P}_{s,\kappa}$ 为 $y$ 的分布。

## 关键结构：参数空间在缝上粘合

映射 $(s,\kappa)\mapsto$ 音位置 $s+\kappa$ 在 $\kappa=+\tfrac12$ 处不单射：
$$(s,+\tfrac12)\ \sim\ (s{+}1,-\tfrac12)\quad\Longrightarrow\quad
\mathbb{P}_{s,+\frac12}=\mathbb{P}_{s+1,-\frac12}\ \text{（逐点相等，与 SNR 无关）}.$$
即参数空间是粘接了邻缝的柱面，$s$ 在缝上不是可辨识坐标。

## 命题（逐符号边界不可分）

设 $\delta:\mathbb{C}^N\to\mathbb{Z}_N$ 为任意仅依赖当前符号观测的判决规则。
则在缝上任一点：

$$\mathbb{P}(\delta\ne s \mid s,+\tfrac12)\;+\;\mathbb{P}(\delta\ne s{+}1 \mid s{+}1,-\tfrac12)\;\ge\;1,$$

且当 $\delta$ 平移不变（对 bin 循环移位协变，工程接收机均满足）时，两项各
$\ge\tfrac12$。SNR→∞ 不改善该下界。

**证明**：由粘合等式，两条件下 $y$ 的分布逐点相同（记 $P$）。同一随机变量
$\delta(y)$ 不可能同时对两个世界都正确：
$\mathbb{P}_P(\delta=s)+\mathbb{P}_P(\delta=s{+}1)\le 1$，展开即得和 ≥1。
平移不变性把 $s$ 与 $s+1$ 的地位对调，两项相等，各 ≥ ½。∎

**注**：证明只用分布相等，因此对任意噪声分布、任意非相干/GLRT 处理、
任意 $\kappa$ 先验形状（先验只影响缝上的后验权重，不影响两条件分布重合）
均成立。高 SNR 使 $P$ 集中在"完美双峰对称谱"上——确定性对称正是命题的
构造性证据（仿真已示：两相邻假设窗口统计逐 bit 相等）。

## 推论：两条且仅有两条逃生口

1. **跨符号 κ 耦合**：公共（或漂移约束的）κ 把逐符号的缝选择绑成全局
   二选一——κ 序列的联合检测/边际化（κ-格 BCJR）恢复可分性，
   全局标签由 CRC/FEC 终裁（镜像双解仲裁为其最小形态）；
2. **外层信道编码**：缝上的错误必为相邻值（±1），经 Gray 为单比特错、
   经对角交织散入不同码字、Hamming 逐个可纠（机制属 Afisiadis et al.,
   arXiv:1911.10245；我们在缝场景实测 SER 0.56 → PDR 0.98）。

## 边界条件（何时命题不适用）

- $\kappa$ 严格已知（oracle 旋转）：缝不落在参数空间内，可分性恢复
  （ORACLE 全过，仿真一致）；
- 多径使滋扰为 κ 矢量：单缝粘合推广为多缝，命题逐缝成立但联合结构未刻画
  （future work：κ 矢量的乘积格 BCJR）；
- 判决规则引入符号间信息（即逃生口 1）或编码（逃生口 2）时，
  "逐符号规则"前提失效——命题不被违反，而是被绕开。
