# 主方案收敛：保留同步不确定性的相干弱包解码器（2026-10-04）

**来源**：用户 2026-10-04 收敛判断（代笔整理，原话要点保留）。
**地位**：**当前主线方案**（优先级高于带外副本/相位 profile/FEC 增强——
均入备选清单）。不改 ED、不增加副本。

## 1. 核心矛盾与主张

> 想充分利用相位，需要可靠补偿；但弱包恰恰难以提供可靠的同步点估计。
> 传统做法（前导定一组参数，payload 全盘接受）在弱信号下放大错误；
> 直接放弃相位又丢掉判决证据。

主张：**前导输出小候选集合（含可信度）→ 每个物理一致假设下充分做相干
处理（保留复数信息、共享参数约束补偿）→ payload 参与选择解释 + 控制重解
成本**。论文贡献的生死线 = 计算复用/候选合并能否超越"多试几组参数"。

## 2. 三步实现（用户原方案）

1. **候选集合**：范围由接收观测决定，禁止事后用真 payload 挑。核心是识别
   哪些参数差异真正改变判决、哪些可忽略。
2. **假设内相干**：同一候选同时解释多个符号（不允许逐符号自由补偿）；
   两段复数统计量按共享同步假设的预测相位关系合并：
   S_i(m;θ)=|a_i(m;θ)+e^{−jφ_i(m;θ)} b_i(m;θ)|²。
   要点：先留复数信息（避免过早取模）；补偿受物理参数约束（不能让错误
   候选任意旋到"最相干"）。
3. **payload 参与选择 + 成本控制**：朴素版=小组候选解码+观测相容比较+
   CRC。真正贡献=复用计算、只在候选产生判决分歧时增加处理。

## 3. 与既有资产的映射（关键定位）

- 相干合并式 = **DeRa 两段窗 Eqs.20–22 同构**：DeRa 在单一 θ̂ 下做，
  本方案在候选集合下做 ⇒ **"DeRa = 同步不确定性问题在点估计假设下的
  特例；我们 = 保留不确定性的通解"**——与族2 分叉（est-compensate vs
  marginalize-soft）叙事咬合。
- G1 救援地图 = 第一步的观测依据（77% 可救）+ 第三步的搜索结构依据
  （等预算 2.2–2.9×）。
- E3-lite = "强前端（CERT sync 全档≥DERA）仍留 ±0.2–0.3 bin 对齐误差
  且 PER 中段未胜" ⇒ **投入顺序第一问（强前端仍留可利用不确定性）的
  答案已有：是**。

## 4. 用户的两条警示（本轮起生效）

1. **等价类不可预设**："不能预先把 CFO–STO 斜线上的点当等价——窗口
   边界、分段相位、随符号位置累积的误差都可能破坏等价。"
   → RIDGE-class 的 net 等价类必须实证检验（G1 err_mask 数据可查表）；
   RIDGE-adaptive 掉点（57%<77%）已是等价不完美的症状。
2. **DTS-1 交叉点未过实现排除**："精细链输给简单链，必须先排除补偿
   接口、相位约定和实现问题，才能当成真实架构矛盾。"
   → κ 格加密消融 + DERA port 残差行为单查，两者已列 v2 清单，升级为
   主线前置项。

## 6. 投入顺序（用户裁定）

1. 证明"强前端仍留下可利用的同步不确定性"（答案已有：E3-lite + G1 A 臂，

## 7. 本轮执行项

- 等价类真实性检验（查表现有 G1 数据）：net 类内 err_mask 唯一模式率
  vs CRC 一致率——若 err_mask 层等价破坏而 CRC 层保持 ⇒ 类作"停机
  判据"有效、作"计算复用单位"无效（分层结论）。
- DERA 式相干合并 × G1 网格（−24 dB）：候选集合下相干处理的 v0 数据，
  与 TREL 网格同种子同噪声可配对比较。
