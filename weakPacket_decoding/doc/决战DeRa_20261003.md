## 2. 物理台账修正（本轮最重要的科学副产品）

1. **定律5 闭式对时钟 SFO 被否证**：真实时钟 SFO 无跨符相位二次项
   （净 c2≤0.024 rad/idx²≈噪声级；πδ·idx² 律属去斜域频率斜坡模型，
   重采样推导二次系数 πδ²/N→0）。DeRa 散焦实测 P=8/16/32@δ=0.082 =
   −0.33/−1.97/−5.75dB，与 **Dirichlet 列走动闭式**（−0.50/−2.02/
   −6.41）吻合 ≤0.7dB；原 −3.45~−15dB 叙事仅在频率斜坡型漂移
   （温漂 CFO ramp / LEO Doppler rate）下成立。**论文漂移章按
   "时钟 SFO（列走动）vs 频率 ramp（二次相位）"分型改写。**
2. **发现 B**：理想栅格重启窗下 payload 整数 bin 走动被窗时漂移近似
   抵消（δ=0.082 全 payload 仅走 ~0.3 bin）；γ 序列斜率 −δ 是 V1/V2
   分裂效应；合成校准 y=−κ_rel−0.25。
3. 我方漂移优势**不依赖 DeRa 崩**（时钟 SFO 下它只掉 0.3dB@P=8）：
   +4dB 来自全场 12.25/8（+1.85dB）+ 选择偏置噪声底免疫（2.1~2.6dB）。
4. 环境维度：捕获帧间段强非噪声突发（86× 帧功率、0.74% 噪声窗让
   搜索型统计量爆表 score 300~1500）——冻结变换免疫。证书不对称性
   的实测形态：DeRa H0 门限比我方高 2.4~2.6dB 且无闭式。

## 3. E2E 缺口结构（未战胜的三个原因，按可修复性排序）

1. **部署锚质量**（dep ν̂0 ±0.2-0.3bin + 对齐残余）：δ=0.02 的 −20dB
   档 PER 从 native .18 恶化到 .77。修复=前导相干平均锚压缩方差
   （D2 遗留清单 #1，最便宜）。
2. **γ-链三个漂移新问题**（本轮定位并部分修复）：y 斜率符号、
   y=−κ_rel−0.25 几何常数、WLS 合角初始化在 δ·span>1 圈落平坦分支
   （需 δ̂ 先验+阶梯）。产线 gamma_link 需吸收。
3. **解码底座 TREL-5 vs DERA demod −1~2dB**（已知主线工作，非本轮
   回归；cert 链已把检测贡献缩到 0.5dB 内）。
