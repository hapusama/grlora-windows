## 0. 总裁决（一句话）

**去斜与采样两轴在单发单收解码链上的机制空地只有一块：去斜的斜率轴
（漂移域，keystone 变换级）；其余自由度全部被自家台账定量封死、或属
自家论文地盘、或被他人占领。** 与增益分类学一致（默认帧解码器侧无
物理律可赢 DeRa）；创新方案不活在逐符号解调器里，活在链路头部——
OTA 实测 4.5dB 级联缺口（真实同步比相干界差）所在的地方。
"更牛的同步"没有被 DeRa 抢走：**它占的只是静态振荡器特例**
（恒 ε、线性 τ_i、"相位噪声/包内 CFO 足够小"假设），动态/漂移坑
（真实时钟、温漂、老化、LEO）无人占领，且 A3 实测 |δ|=0.002~0.024
bin/符（43 符帧总漂 0.1~1 bin，SF10 全负/SF11 全正）——真实对象存在。

## 3. 本轮新贡献（三条合成 + 一个锚点）

### 3.1 keystone 预编码的具体形态与复杂度对比

雷达 keystone 在 (慢时间 i, 快频率 k) 平面上做**逐列慢时间重标度**
（窄带下 u_k(i) ∝ i·k/f_c 代换，离散实现=每列 chirp-z/插值），使
**未知斜率**的线性走动在重标度坐标系里与斜率解耦——一次变换覆盖全部
线性漂移假设。LoRa 映射：K×N 谱图（DeRa 第一级输出）上，峰走动
k_i = k_0 + i·δ 与跨 chirp 相位 φ_i = φ_0 + 2πκ·i 的耦合结构=雷达
距离走动×多普勒的精确同构；keystone 后单一第二级 FFT 得到走动无关的
相干脊，**替代 DeRa 20 候选 × 5×5 refine = 500 次评分搜索**。
注意：keystone 是逐列重标度（chirp-z 级），不是单一相位乘——相位乘
只能修已知斜率的走动（那正是 DeRa 的 est-compensate）。
二次相位残余（斜率失配 β'−β）keystone 不碰，但 DeRa 自估 SF12/40kHz
下仅 ~0.44 rad——可忽略；随机相位游走实测 σ≈0.11 rad（e^{−σ²/2}≈0.4%
损失）同样边角。

### 3.2 证书不对称性原理（新命题）

**免估计的相干积累天然可证虚警；估计-补偿型的检测统计量天然不可证。**
理由：keystone = 噪声上的固定线性变换 → 复高斯每格保持高斯（列间相关
已知可推导）→ H0 分布闭式 → CFAR 门限可解析（Kang'23 已示范经典统计量
的门限优化方法论在 LoRa 可发表）。DeRa 的统计量 = 数据驱动排序的候选表
+ 模型评分 + CRC 序贯反馈 → H0 律依赖自适应排序（相关分数的序统计量
+ 序贯 CRC 门），无闭式，只能 Monte-Carlo；且 CRC 吸引子效应
q≈1e-3（≈2⁻¹⁶ 的 87 倍，已实测入库）恰好坐进这个缺口。
**这把空间②（机制）与空间③（证书）从"合体"升级为"同一枚硬币"**：
不是两个卖点拼盘，是机制选择决定了可证性。对 DeRa 的差异化一句话：
"DeRa 给了 dB 没给证书；我们的 dB 未必更多（漂移域 oracle 上限
+2.33dB 实测），但是可证的 dB。"

### 3.3 复合检测统计量（第二篇的检测器一句话定义）

**对 preamble + sync word + SFD 全已知场（12.25 chirp）做 keystone
校正的跨 chirp 相干积累，附 CFAR 门限。** 三个属性同一统计量：
全场相干 +1.8dB（10log10(12.25/8)，DeRa 只积 8 前导、sync/SFD 仅作
验证）× 漂移鲁棒（keystone 结构性免估计）× 虚警可证（3.2）。
边界诚实：keystone 只作用于已知场（公共轨迹存在的前提）；payload
符号 bin 未知 → payload 漂移跟踪归 γ-trellis 主线，keystone 不越界。

### 3.4 PreCo'25 对偶锚点（防御段弹药 +1）

PreCo（WoWMoM'25）：**TX 侧**加长前导/编码换低于标准门限接收。
与我方 RX 侧负定律（coding-as-detection 数据税 10~11.5dB、绝对上界
≤1.1dB）构成严格对偶：他们花 airtime 改波形买 dB，我们证明纯接收机
侧无此税可收。写法："TX-side preamble extension (PreCo'25) vs
RX-side code exploitation——我们给出后者的负定律"。

## 5. 实验落地（同日完成）：fullfield_cert_detect_20261003
