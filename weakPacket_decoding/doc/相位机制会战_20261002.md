## 0. 总裁决（三句话）

1. **机制核心查新空白成立**：帧内峰 bin 相位轨迹作为随机过程进弱包解码
   统计量——无一先例（三面墙：LoRaPDA 确定性补偿碰撞场景 / Nguyen'21

2. **相位红利真实但结构被拆穿**（E2+E3 归因解离）：genie 上界 ≥1.5dB
   （窗界、PER 131:2）中，**SER 份额=盲 κ-line 可独立拿走（+0.50dB）**，
   **PER 份额=相位相干（turbo 盲端捕获 55~61%、配对 71:0 零败北）**。
3. **全盲边缘化版本被证伪并升格为失败定律**："κ 可以边缘化，Φ 不行
   （不能这样边缘化）"——marginalize-vs-estimate 脊柱延伸到相位域的
   第一个定量边界。

## 1. 新 OTA 物理律（E2 探针链，全部数值验证）

1. **STO 滑动主导律**：payload 峰 bin 相位增量原始 1.75 rad（≈均匀
   2π/√12=1.81）的 dominant det 项 = **d = 2π·τ·Δv/N**；逐帧 τ̂ 拟合后
   增量降到 **0.19 rad（浓度 0.982）**。奇偶律、二次项、φ_H(c) 分箱均
   排除。τ̂ 按 capture 整数聚类 {−1.1, 0, +1.05}（20帧≈−1、7帧≈+1）。
2. **半 bin 音位差**：payload κ₀≈−0.05 帧间稳定，preamble κ∈0.24~0.61，
   相差≈半 bin——E1 的 pay/pre 幅度比 0.63 = D(0.5)=0.64 半 bin 损耗。
   **这是 κ-line +0.5dB 的物理来源，也是主链锚定复核项（见 §5）。**
3. εν(SFO) ∈ [−0.017, 0]，17/28 帧 |>0.003|；|Z| 真音 ±0.1 bin 平顶 +
   分裂纹波 ⇒ 逐符号 |Z| argmax 不可作 κ̂（必须 γ-链/κ-line）。
4. 前导 σ_walk 中位 0.083 rad（Wiener，白性过检）、幅度 CV 0.08——
   硬件过程确实"稳"，用户"让它稳定"的直觉在条件化层面成立。

## 3. 归因解离（本轮主科学产出）

**κ-line 修孤立符号错（SER 维度）；相位相干修成簇错、只在 FEC 之后
显形（PER 维度）。** E2 的 genie 红利 = SER 份额（可盲取，估计精度类）
+ PER 份额（相位，盲端只能靠 CRC 仲裁的 turbo 拿约一半）。genie 上界
本身被 E3 判定部分自实现——盲端现实收益：SER +0.5dB（κ）+ PER 捕获
55~61%（相位）。

## 4. 论文定位（待用户对齐，未改 COGNITION）

- **相位降级为"κ-line 章 + 相位-FEC 节"**，不作独立机制章：
  主轴仍是 κ 格 marginalize-soft（ML-tight 认证 + 半 bin 恒等式 +
  负定律族），相位 turbo = "软接口+同步残差吸收"的定量证据节。
- 三面墙对表收尾：LoRaPDA/Nguyen 有确定性补偿或导频；我们的全盲
  边缘化版本被自家实验证伪——**引用式划界比声称式划界更硬**。
- CCF-A 缺口不变（方案挖掘 R2 三件）：δ-keystone E2 落地、DeRa port
  同表、规模评测。相位会战净增：机制空白域的 OTA 定量上界 + 解离
  定律 + 盲 κ-line 立即可入库。
