## 0. 收敛核心：Frame-as-One（折返链锁相格 / γ-链接收机）

**一句话**：OS 抽取后，每个去斜符号窗**严格塌缩为一条纯复单音**（wrap 两段
别名拼合），窗边界相位推进与数据无关、恰为 2πκ_i；于是每符号的 wrap-split
两段投影差分相位 γ_i = angle(V₂V₁*) = πκ_i 是**候选盲、帧相位盲**的免费 κ
测量；整帧全部段投影打包，对（φ₀, κ₀, δ）做加权线性最小二乘（rank-2/3 闭
式），κ 的后验方差 s_i 以特征函数衰减因子进入统一度量——**DeRa（全相干极
限）与 LoRaTrimmer（非相干极限）被证明是同一个闭式的两个退化极限**。

**为什么这算"神招"而非数值加权**：一个恒等式（窗边界相位推进 = 2πκ_i）
承重全部机制；机器（Viterbi/加权 LS/Rician 度量）全是借来的成熟件；一句话
+ 一个公式，零调参。

## 1. 数学脊柱（主脑证明，probe1 实测吻合）

**纯单音塌缩**（OS=4，折返点 (N−c)·OS 在采样栅格上）：按 OS 抽取后，真符
号 c 的去斜窗两段在 N-bin 域别名拼合，桥接相位 e^{2πj(N−c)}=1，整窗为

$$x_i[m]=A\,e^{j\phi_i}\,z^m+w_m,\qquad z=e^{2\pi j\kappa_i/N},\quad m=0..N{-}1$$

**γ 恒等式的精确证明**：两段部分和 $S(L)=\sum_{m<L}z^m=\frac{1-z^L}{1-z}$，
前段长 $L_f=(N{-}c)$、后段长 $L_t=c$（N-bin 域）：

$$V_1=Ae^{j\phi}S(L_f),\qquad V_2=Ae^{j\phi}z^{L_f}S(L_t)$$

$$\angle(V_2V_1^*)=\tfrac{2\pi\kappa L_f}{N}+\arg S(L_t)-\arg S(L_f)
=\tfrac{2\pi\kappa L_f}{N}+\tfrac{\pi\kappa(L_t-L_f)}{N}
=\pi\kappa\cdot\tfrac{L_f+L_t}{N}=\boxed{\pi\kappa}$$

（用 $1-e^{j\theta}=-2j\,e^{j\theta/2}\sin(\theta/2)$，θ∈(0,2π) 时 arg=θ/2−π/2
精确成立；段长和 $L_f+L_t=N$ 使符号值 c **完全消去**——probe1 的实测
γ=πκ 不是近似，是恒等式。）

**统一度量（精确后验均值，非近似）**：κ ~ N(m_i, s_i²) 时

$$\Lambda_i(c)=|V_1|^2+|V_2|^2+2\,\mathrm{Re}\{V_1^*V_2\,e^{-j\pi m_i}\}\;\underbrace{e^{-\pi^2 s_i^2/2}}_{\text{特征函数衰减}}$$

恰为 $E_\kappa\big[|V_1+e^{-j\pi\kappa}V_2|^2\big]$（相位以一次谐波进入，Gaussian
特征函数逐项精确）。两个极限自明：s→0 = DeRa 全相干合并；s→大 = LoRaTrim-
mer 非相干 |V₁|²+|V₂|²。**"marginalize vs estimate"的哲学对立被升维成同一
闭式的连续工作点选择**——这是论文引言"虚假前提"叙事第一次拿到数学脊柱。

## 2. 三方入场路径（辩论记录）

2. **偏差题（可辩护，须实验背书）**：z_i 在判决错误的符号上被污染——但错

   curse（测量期望不依赖自己此前判决的正确性），不是无条件下无偏。
3. **恒等式脆弱题（可辩护）**：栅格条件=整数 OS+整数 c（本系统满足）；亚

4. **叙事题（升格路径）**：不是"修 DeRa"——是"给出弱包解码器设计空间的

   点实现且附带软接口"。
5. **复杂度题（无伤）**：F/T 投影矩阵已存在（port v2），γ-链只加 O(N)/符号

## 8. R2 专职审稿人裁决（已回归，全文收录）

**总判决：六条攻击零条直接毙掉，但三条重伤（分解题/偏差题/楔子存在性题，
第七条为 R2 自行补充的最狠一条）。数学脊柱是真钢筋（γ 恒等式证明挑不出
错、两极限统一干净），但上面目前只搭了一间 0.2dB 的棚子。E2 与 E3 是仅有
的两根承重柱。**

### 8.1 逐条处刑摘要

1. **分解题——重伤**：1dB 帧池化是 DeRa 的不是我们的（TREL-5 对修好的
   DeRa 是 −1dB）；对 Fig.9(b) 的择优取证被拒——它同时证明 est-compensate
   冠军**在漂移下不脆**（DeRa 只掉 0.1/0.5/4.8 个百分点）。但 R2 指出真
   裂缝：DeRa 的漂移应力是**随机游走**（零均值自相消，50 符号累计 std
   ~0.34 bins），而**确定性 SFO 是单调二次累积**（20ppm@SF12 → 0.082
   bins/符、4 bins 累计行程 = DeRa 应力测试的 12 倍），且与其线性帧相位
   模型不兼容——问题不是我们造的，是 DeRa 没测的那个象限。表演性扫频
   （δ≥0.2 ≈ 400ppm）会被当笑话。
2. **偏差题——重伤**：κ≈0.5 处错判与高权重**同源**（泄漏 0.79×、错判符
   号以 ~0.62× 权重、π 相位翻转进入 WLS）——"加权在最需要它的地方失效"；
   p_e=0.2（悬崖区）时 WLS 输入 20% 污染。"候选盲=无偏"话术收回：测量
   **算子**候选无关 ≠ 测量**值**无条件无偏（判错时测的是 π(κ+c−ĉ)）。
   存活条件=E4 注错实验；若崩则唯一出路是 PSP 联合候选-κ 边际化（须承认
   机器是 Raheli'95 的）。
3. **撞车题——可辩护（更瘦）**：LoRaTrimmer Eqs.19-30 **本身就是 uniform
   先验的相位边际化**（Bessel I₀），我们的统一闭式=部分相干检测 folk 定理
   （Lapidoth 系/Ip&Kahn'08）的**精确实例化**——"定理"降格"引理"。剩余
   重量在工程闭环：候选盲差分测量 + **自标定 s_i** + κ-边际化 LLR，此组合
   查新无人占——够 SECON/TIM，够不够 MobiCom 存疑。要求：related work
   里**自己先说** Trimmer 是我们闭式的 uniform 先验特例。
4. **恒等式脆弱题——可辩护附条件**：符号内 chirp-rate 失配给 γ 的系统偏
   差 ~0.14 bins（SF12/40kHz 界），是被测量 δ=0.082 的 **40%-170%**——
   "精确恒等式"必须条件命题化（E5 兑现为前提），非整数 OS 直接碎栅格。
5. **叙事题——可辩护**：(a) 把 −1dB 翻转成设计空间内部证据（s→0 端点胜
   离散格点=连续工作点值钱）；(b) 主叙事="s 参数化设计空间+自标定工作点+
   第一个 κ-边际化软接口"；(c) system claim 锚定 **LR-FHSS 80ppm 规格**：
   "首个在 ≥20ppm SFO 下无需搜索交付相干合并增益的 LoRa 解码器"。
6. **复杂度题——无伤**（flop 表须计入 DeRa Stage-3 重试期望次数）。
7. **楔子存在性题——重伤偏毙（R2 自补）**：DeRa 检测级 CFO 90 分位误差
   折算 **0.006-0.014 bins**（SF7/SF10/SF12），vs 我们帧池化 σ_κ̂≈0.02
   bins——**同一量级，DeRa preamble 可能更好**。楔子只剩两根牙签：(a)
   帧内时变（确定性 SFO 二次累积+陈旧常数先验）；(b) 软接口（但现有证据
   是负资产：BCJR .192 vs DERA 硬读出 .085）。**且 port v2 缺 Algorithm 1
   Stage 3 与检测级——我们在和一个缺闭环重试的 DeRa 比；"不坑 baseline"
   红线双向，E3 补齐前禁止任何"vs DeRa 胜利声明"。**

### 8.2 幸存者清单（全文见上轮回归原文，要点）

- **E1** GT 诊断（|δ̂|<0.01 bins/符 的帧占 ≥90% → 漂移支柱移出默认帧叙事）；
- **E2 确定性 SFO 扫频（论文的命）**：SF10+SF12 × δ∈{0.02,0.05,0.082,0.1}
  （锚定 20/50/80ppm 真实晶体档）；过线：SF12/20ppm 处 γ-链劣化 ≤1.5×
  且 DERA-v2 ≥2×（或门限差 ≥0.5dB）；交叉点 δ*≤0.05 方可宣称真实硬件域；
- **E3 真实同步残差域（生死项）**：oracle vs real gap 矩阵（PC-Ridge ×
  {Trimmer,UniChirp,DERA-v2,γ-链}），real-sync 下 γ-链对 DERA-v2 门限差
  ≥0.5dB；**先补齐 port Stage 3 + 检测级 CFO 传递**；
- **E4** 注错 p_e∈{0.01,0.05,0.2}（p_e=0.05 时 PER 劣化 ≤0.2dB）；
- **E5** 恒等式应力（τ_res × 符号内 ε，γ 偏差 ≤0.01 bins 或闭式修正后达标）；
