## P0 — 两场定生死的仗

### P0-A：v2 复用引擎（COH-MULTI 的机制实体）

**做什么**：payload 段谱 gather 化——每符号窗一次高分辨率 FFT 预计算，
候选 θ 只做"两段解析峰位 gather + 相位旋转合并"
（S_i(m;θ)=|a_i(m;θ)+e^{−jφ_i(m;θ)}b_i(m,θ)|²，与 DeRa 检测段 §4.2
的 reusable FFT precomputation 同构，延伸到 payload 解码段）+
判决分歧触发的细化调度。

**已知风险（必须带消融）**：两段峰位模型随候选变化——port v1 曾死于
固定中点切分（native SER 0.14）。v2 必须：
1. native 全对（28 帧 SER=0，与 port v2 时域版对齐）；
2. **与时域重算版逐位等价自校验**（协议 §6 快路径标准）——等价不了
   就量化偏差并声明近似；
3. 速度基准：候选增量成本 vs 0.17 s 全重跑（目标：>10× 加速，
   即把 K=65 的 1.41 s 压到 ~0.2 s 量级）；
4. 次优切分消融（固定切分 vs 逐候选精确切分的 SER 差）。

**验收**：W3-battle 表在 v2 引擎上复现（恢复率不掉、时间降一个量级）。
**为什么是 P0**：E5 已证"单纯排序不够"——计算复用是论文机制贡献的
实体，没有它创新点 3 只有一半。

### P0-B：D1 终战——对 DeRa 实体的同表 PER（去代理化）

**做什么**：五版本对照表（用户 2026-10-04 主方案表）：
1. 当前同步点+相干解码（=A0）
2. 更强单点同步+相干解码（强前端单点）
3. 少量候选+相干解码（COH-MULTI）
4. 等预算普通候选搜索（BLIND）
5. 真实参数辅助诊断版（=C 臂，只供同步信息不给 payload，标注诊断）

STAGE3 臂去代理化：接 DeRa 自己的检测排序（其两级 FFT 前端候选池
前 5），不再用 net 序代理。全链形态（实验A）+ 解调半场形态（实验B）
各一张；主表=全链 PER；同表含 DeRa 实体、DERA×TRIMMER、TREL 家族。
多档（−20…−26）× ≥5 种子。

**验收**：COH-MULTI 对 DeRa 实体在同预算/同表下 PER 全档或主要工作区
档领先——这是把创新点 3 兑现为战绩的一仗；赢不了则回 E1 归因重诊断。
**依赖**：P0-A（深预算的实时性主张）；可先以重跑版跑通表格再换引擎。

## P1 — 卫生与排除（把已有结论钉死）

1. **DTS-1 交叉反转的实现排除**（升格"架构矛盾"的前置）：
   - κ 格加密消融（TREL 格 0.25→0.125）：若 ε∈(0.1,0.3) 区 TREL 崩塌
     被修复 ⇒ 确认格间失配机制；
   - DERA port 相位约定单查（残差下崩=合并被破坏 or port 约定问题）。
2. **深档/引擎扩展**：DERA 相干网格补 −22/−20 档（现仅 −24）；
   全部实验种子 3→5。
3. **hard 符号序列落盘**：runner 补存逐点 hard 判决（替代 err_mask
   代理），E3 等价类结论复核。
4. **SER 等高线图**（关口 2 正式产物）：逐单元 (ν,τ) 平面 SER 等高线
   + κ 格 0.25 周期次结构检验 + err_mask 包内位置积累分析
   （"误差伤害随位置积累"性质，用户关口 2 第三性质）。
5. **跨噪声稳定性定量**（关口 3 最小版）：同帧 3 种子间救援点集合
   Jaccard / net 分布 KS 检验（数据已有，纯分析）。

## P2 — 泛化与外部效度

1. **跨批次自采**：USRP+SX1276 现成，不同日期/位置采 2–3 批（管线零
   适配），关口 3 批次留出测试。
2. **LoRadar 完整接入**（漂移域压力档）：逐 session 频带定位自动化 /
   sync word 识别（旁路 framesync 改 CRC/结构判据，过负控）/ 大 CFO
   搜索范围扩展 / GT 自产率实测。价值=真实大漂移场景（本地造不出），
   同时服务第二篇（漂移域）。
3. **机制对账**：Afisiadis Eq.22 泄漏公式数值 vs E1 PLAIN 臂实测
   （native PLAIN@ε=0.3 实测 .103 > 无噪解析预期——偏差指向 ν*，
   与 ±ε 不对称互证）；净偏移守恒的解析推导（挂 Xhonneux CFO/STO
   相位定理 + 两段窗模型）成文。
