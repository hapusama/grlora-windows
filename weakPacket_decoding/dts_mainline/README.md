## 这条线是什么

一句话：**弱信号下前导同步参数估不准时，不让"精细相干解码"为错误的
点估计陪葬——把不确定性保留成候选集合，让 payload 判决引导解码，
并让集合的代价逼近单次解码。**

对手与参照：DeRa（MobiCom'26，MSU）。定位：DeRa 的两段相干合并是
同步不确定性问题在**点估计特例**下的解；本线做**保留不确定性的通解**。
