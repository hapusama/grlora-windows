## 3. 结论：DeRa 解码增益的分解（K1f/K2f 命中、K4 上限突破、排序定案）

1. **两段滚动参考 = 地基（必需结构，非增益项）**：去掉它（fft 混叠
   和臂）门限区全灭（−22 .386 / −24 1.0）；−20 以上无损。机理=
   **混叠定律（本轮新发现）**：信号 fold 频率跳变 = 1/os 周期/样本，
   平参考 FFT 在 os=4 把能量劈进相距 N bin 的两个混叠音（干净符号
   峰位精确二值 {v+2, v+2−N}）；os=1 跳变=整周期混叠为零=GT 纯 FFT
   链能解的原因。**port 的参考滚动 = 让参考 fold 对齐候选 fold，
   两段落回同一 bin**——DeRa two-section 的必需性由此而来。
2. **Stage-2 ML φ̂₀ = 最大解码级部件（全档性）**：s1（φ=0 合并）
   全档损失 .136-.529，**连 native 都有 .143**——段间相位 γ 实测
   ±1.6~2.9 rad，φ=0 合并在平衡段符号上对消（port docstring 的
   "κ→0.5 相消"预言首次被量化）。φ̂₀ 与相干合并分管两个 regime：
   **φ̂₀=高位对消防护（全档），相干合并=门限 2.2dB**（nc−full 仅
   −24 显形 .464）。
3. **Δ0/CRC 仲裁 = 约定吸收必需品**：noD0 全档 1.0（锚→demod 的
   整数 bin 约定偏移 mode_off 常数项，无重试即全灭）——仲裁不是
   增益而是 correctness，DeRa 25 判次与我方 Δ0 同源。
4. **回答用户**：DeRa 解码器增益排序 = **① ML φ̂₀ 相位自适应（全档
   .14-.46 PER）≈ ② 相干合并（门限 +2.2dB/.46）＞ ③ 两段结构
   （必需地基）＞ ④ CRC 重试（必需品）**；解码器之外，DeRa 系统
   级优势的大头仍是其前端对齐（v19 注记不变，v14 重构待落）。
