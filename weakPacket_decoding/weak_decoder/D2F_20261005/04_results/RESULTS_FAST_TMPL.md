# RESULTS — fast_tmpl 精确模板接收机快实现（2026-10-05）

> 主线 = HANDOFF §4 下一刀：每候选 ε 分数重采样 → 常规 dechirp-FFT
> （port 结构不动）。基准 = `01_core/ref_template.py`（行1/2 已证漂移域
> +1.1~+4.8dB 统计量余量）。规范 = EXPERIMENT_PROTOCOL v1.1（§5A 终判
> 只认全链 CRC）。本文件先预注册预测，后填实测（房规）。

## 0. 数据与口径（与前战一致）

- SF10 OTA 28 帧（P∈{8,16,32}），δ 注入 = 整段 IQ 先注入后加噪
  （resample_sfo(ε=δ/N)，origin=场首），同噪声喂所有臂（铁律 1/2）。
- 机制实验（实验B 哲学）：参数在干净注入信号上估计冻结；链战全盲。
- GT 只评分不进链（铁律 3）；PER=CRC16 终判（铁律 4/§5A）。

**实现期实测定律（诊断阶段钉死，不属预测）**：
- L1 去斜 STO 免疫：整体分数延迟**不移动** tone 分数 bin 位（只挪 fold
  瞬态）；整数记账在 \|d\|≈0.75 采样处翻转 ±1（链上 Δ0 合法吸收；
  机制对拍必须读 mode(argmax−gt−1) bin——初版读固定 (gt+1) 曾得 −24dB

- L2 tone SNR 平顶：native 下 \|d\|∈[1.5,3] 采样两侧同高（46.4 vs 模板
  46.1dB）；τ̂ 符号 = advance(−τ̂₀)（z_full u=n+s−τ₀ ⇒ 符号起点 Mk+τ₀）。
- L3 mode_off 帧级常数 {0,+1,−1}（锚整数记账），随帧翻转、帧内恒定。

## 2. 验收①②③ 实测（fast_tmpl_check.py，28 帧 δ=0.02 + δ=0 sanity）

**① 统计量无损：PASS（28/28）**。帧中位差（fast−template，读
mode bin）全体 ≥ −0.004dB：med **+0.217dB**、IQR [+0.06,+0.56]、
max +1.65（f09）。全为正 = 快版（修复+port 合并）**处处不输**完整
模板、多数帧胜 0.2~0.6dB——与行1 定律（port ML φ̂₀ 自适应胜开环
模板 0.8~3.2dB）同向，非重复补偿特征（重复补偿会呈大负值；初版
读固定 (gt+1) bin 曾得 −24dB 假 FAIL，即 L1 整数记账翻转现场）。
mode(argmax−gt−1)：27 帧 0、1 帧 +1（帧级常数，Δ0 吸收）。
→ **P1 成立**。

**② ν̂₀ 约定：PASS**。δ=0.02 native，oracle τ̂ 下 **28/28** 过 CRC
（ser=0 为主，个别 ser≤3 由 FEC 纠）；δ=0 盲梯 native **28/28**。
dep4 锚 ν̂₀ 直旋（修复后不居中不补走动）约定成立，未见 0.146bin
类生死线翻转。→ **P2 成立（28/28 ≥ 预注册 26/28）**。

**③ 盲 τ̂₀：解码 PASS / 预测 P3 失准（系统性偏置，非噪声）**。
前导盲估 vs payload oracle：|Δτ| med **2.15** 采样，28/28 帧
|Δτ|>1——**系统性 +2.2 采样同向偏置**（盲估 4.5~4.65 几乎常数 vs
oracle 2.05~3.15）= 前导参考点 vs payload 参考点的**约定差**，非
估计方差（两分布均近似常数、帧间不散）。盲 τ̂ native 28/28 过 CRC
（偏置落在 tone SNR 平台 |d|∈[1.5,3] 内，L2）。低 SNR 代价由
§3 机制战 E_fast_blind vs E_fast_oracle 差分裁定（见下）。

判定：**验收①②③ 通过，快实现入列**；P3 按预注册如实记失准
（判据以解码为准的条款保留，偏置机理进 FINDINGS）。

## 3. 机制级噪声战（fast_tmpl_mech.py，δ=0.02，seeds 0-4，n=140/档）

**终表（PER；统一 demap_judge 仲裁 Δ0∈{0,±1,±2,±3}；参数干净冻结，
实验B 哲学）**：

| SNR | E_fast_oracle | **E_fast_blind** | E_fast_blind_ab | A_full | D_ladder_A |
|---|---|---|---|---|---|
| native | .000 | **.000** | .000 | .036 | .393 |
| −24 | .350 | **.086** | .086 | .221 | .979 |
| −22 | .064 | **.029** | .029 | .086 | .736 |
| −20 | .014 | .014 | **.007** | .064 | .671 |
| −18 | .014 | **.000** | .000 | .043 | .543 |

- **P4/P5 成立并加强**：E_fast_blind 全档最优——−24 对 D_ladder_A
  **11×差**（.086 vs .979）、对 A_full 2.6×（.221）、−22 对斜率梯
  25×（.029 vs .736）。时间基修复（重采样+τ̂₀）兑现行2 余量的
  机制级证据链闭合：斜率梯只修音位走动（F8），修不了 wrap 边界
  + TO 相位（F1/F2），fast 全修。
- **复制健康证**：A_full native .036、D_ladder native .393 与
  sfo_sto 发表数字**逐位复现**（同构造同噪声 seeds 0-1 子集扩展到
  0-4；−24 A_full .221 vs 发表 .250 n=56，方向一致属种子数差异）。
- **τ̂ 仪器翻转（重要归因发现）**：E_fast_oracle（GT 码值 payload
  est_tau0≈2.05"oracle"）−24 **.350 反而最差之一**；前导盲估
  τ̂_pre≈4.1-4.6 落在解码最优。即：**非相干 |Z|² argmax 的 payload
  τ̂ 系统性偏低 ~2 采样**（平台/Fresnel 结构弱仪器，F5① 的加强版：
  不止旁瓣，argmax 本身偏）——前导模板（code0 公知、fold 贴窗尾）
  目标函数更良性。"oracle"臂实为"低偏仪器臂"，验收③的"+2.2 偏置"
  解读翻转：**盲前导估才是对的，payload GT est 偏低**。
- **(δ_c,τ̂) 联合补偿简并**：−24 救回 121/128 落在 (0.01, τ̂4.1-4.6)
  而非 (0.02, ·)——CRC 仲裁的是**参数对**不是单参数；半修复+准 τ̂
  胜过全修复+偏 τ̂（fold/TO 相位 > 残余漂移，与 F2 相位主通道一致）。
  P8 预测（δ_c 集中 ±0.02）失准，按预注册如实记。
- 败局结构：−24 失败 12 单元帧级集中（frame21 P=32 五种子全灭等），
  −22 失败为整帧崩（位置图 [1400×3,700] 全符号错 = 门限型全灭非簇状）。
- B 列（trellis）在机制层近零增益（−20 仅 1 单元差）——修复后 κ≈
  常数，A 列 port 全包；B 列价值保留在链战（检测噪声下 A 列失败时）。

## 4. 链战 §5A（fast_tmpl_battle.py，全盲，4536 单元满额，20 种子）

**同噪声 join**（m3p 派生）：u = m3p2 checkpoint（斜率梯链）；
DeRa = m3p checkpoint；uf = m3p2 全败单元上 fast 救援臂现算
（dep4 检测重建→δ 梯 ladder_order(δ̂)→**含噪段上前导盲估 τ̂_pre 逐
候选**→A/B 两列→Δ0 CRC）。u 过即跳过 fast（单调零回归）。

|---|---|---|---|---|
| 0 | native | .000 | **.000** | .000 |
| 0 | −24 | .475 | **.216** | .679 |
| 0 | −22 | .071 | **.043** | .079 |
| 0 | −20 | .032 | .018 | **.005** |
| 0 | −18 | .013 | .004 | **.002** |
| .02 | native | .000 | **.000** | .143 |

| .02 | −22 | .173 | **.057** | .246 |

| .02 | −18 | .011 | .004 | **.164** |

- **δ=0.02 全档首胜 DeRa（P7 成立并超额）**：−24 .241 vs .673（2.8×，
  M3P2 的深端未胜 .863 vs .673 **反转**）；−22 4.3×；−20 13×；−18
  41×。具名缺口"port 切分点漂移"由重采样修复兑现。10%PER 内插：
  **−22.8 vs DeRa 全档不达 10%**；对 m3p2（−20.76）= **+2.0dB**。
- **δ=0 深端同向大胜**：−24 .216 vs .679（3.1×）。10%PER 内插
  **−23.0 vs DeRa −22.2（+0.75dB，M3P2 时代为平手 −22.14 vs
  −22.07）**；50%PER ≥−24.x（.216@−24，−26 未入战声明）。
  δ=0 的救援机理 = 纯 τ̂₀ 对齐（advance(τ̂_pre)）——F7 的 τ₀ 项
  1~3dB 在 δ=0 深端同样可兑现。
- **零回归（P6 成立）**：uf ≤ u 全部 10 格，浅端 −18/−20 DeRa 仍略
  优（.004 vs .002 / .018 vs .005，m3p2 已知浅端地板，fast 不伤）。
- **救回归因（P8 修正）**：δ=0.02 −24 救回 348/483，**330 在
  δ_c=0.01**（17 在 0.02）；δ=0 −24 救回 145，**96 在 δ_c=−0.01**。
  CRC 仲裁的是 (δ_c, τ̂) 参数对——"正确 δ 候选"并非被选出，选出的是
  解码可行对（联合简并，mech §3 同律）。δ̂ 精度叙事在参数对层面失效，
  如实降级。
- join 覆盖：噪声档 n=560/格全（含 ~100 join 缺口单元全链现算补齐，
  u 列以 m3p2 join 为准声明）。
- 口径注意（沿袭 M3P/M3P2 声明）：DeRa 臂 = m3p checkpoint 同噪声
  数字（检测级 port 瘦身版，缺 20 候选×25 点精化；δ=0 漏检差按
  "待确认"持有；v14 重构落地后双版本改判）。

## 5. 结论与去留

1. **验收四条全过**（①统计量 28/28、②约定 28/28、③盲 τ̂₀ 解码全过
   +偏置机理翻转澄清、④§5A 链战 CRC 终判）——快实现（每候选 ε
   分数重采样 + 前导盲 τ̂₀ + 常规 dechirp-FFT，port 结构不动）**入列
   为 D2F 现行链第三级**：m3p2 链全败 → fast 梯救援。
2. **战绩**：δ=0.02 全档首胜 DeRa（10%PER −22.8 vs 不达；+2.0dB over
   m3p2）；δ=0 深端 −24 3.1×、10%PER +0.75dB（平手→胜）。
3. **机理沉淀**（FINDINGS F9/F10）：去斜 STO 免疫/整数记账翻转/
   tone 平台三定律；payload |Z|² τ̂ 仪器偏低 2 采样 vs 前导盲估贴近
   解码最优（§5A 下沉到估计器）；(δ_c,τ̂) 联合简并——fold/TO 对齐
   > 残余漂移（F2 相位主通道第三次验证）。
4. **去留**：浅端地板（DeRa −18/−20 略优）不动；−26/δ=0.082 未入
   战；τ 细梯（±0.5 采样 ×3）可再收 −24 约 .03（GT 扫描裁定 8/12
   失败为信息受限，天花板 .057 vs 现状 .086）——列为下一刀候选。
   行3-5（块跟踪/软反馈/上界对照）入口不变（HANDOFF §4 原计划）。
