# D2F 接收流程说明（人类可读版）

> 目的：给"第一次接触 D2F 的人"讲清楚这条弱 LoRa 包接收链**每一步在做什么、为什么这么做、验证到什么程度**。不含内部实验代号流水账（代号对照见文末）。数字口径：SF10 真实空口数据 28 帧 + 纯 AWGN、20 个随机种子、PER = CRC16 终判（对 DeRa 全链基准）。维护者文档：README.md / FINDINGS.md / HANDOFF.md（同一目录）。

## 0. 一句话与全景

**D2F（Decode-to-Finish）**：一条"检测 → 时间基修复 → 仲裁解码"的弱包接收链。核心思想一句话——**同步不必一步做对：检测给证书、修复带模型、解码来收尾，CRC 是唯一的裁判**。

全景按执行顺序：

1. **门扫**：滑窗去斜找"谱尖峰持续出现在同一频点"的事件，得到包的候选起点（top-3）。
2. **偏移筛查**：把起点粗对齐到 ±256 样本内（前导码粗对齐）。
3. **两级验证**：非相干候选筛选（能量谱取能量最高的 16 个频点）→ 全场相干验证过固定门限，顺带输出 SFO 走动率估计 δ̂。
4. **CFO 精化**：把选中的候选频点插值到 0.011 bin 的连续值 ν̂。
5. **常规解码尝试**：频率居中 + 斜率梯反走动 + 两路解码器（A/B）+ CRC 逐级仲裁。
6. **兜底（前一步全败才触发）**：时间基修复重试——ε 候选梯精确逆重采样 + 前导盲估 τ̂₀ + 分数时延对齐，修复后再解码仲裁。

其中 1–4 合称**检测与参数估计（M1）**，5 与 6 的仲裁架构合称**仲裁解码（M3）**，6 的修复本体是**时间基修复（M2）**。

## 1. 第一步：检测与参数估计（M1）

> **省流：一段含噪 IQ 进去，四个量 + 一个判决出来——①有没有包（虚警 1e-3 固定门限）②包在哪（场首起点，±256 样本）③CFO 精估 ν̂（0.011 bin）④SFO 走动率 δ̂（0.01 bin/符号）。不输出 STO/τ̂₀（亚采样时延留给解码层兜底）。内含五步：门扫 → 偏移筛查 → 候选筛选 → 相干验证 → CFO 精化。**

**要解决的问题**：这段噪声里有没有包？在哪里？三种同步损伤各是多少？——低 SNR 下这几个问题相互纠缠。先把三种损伤分清楚（后文统一用这套叫法）：

- **CFO（载波频偏）**：收发载波差，**所有符号的音位整体平移同一位置**——由候选频点假设吸收，CFO 精化负责收尾；
- **STO（符号定时偏差）**：恒定的到达时刻偏差，**不移音位**（去斜对常数时延钝感），只留下相位与折叠点位置效应——由解码层的 τ̂₀ 兜底；
- **SFO（采样钟速率差）**：时钟快慢不同，到达时刻**逐符号线性累积**，表现为**去斜音位每符号走 δ 个 bin**（记作 SFO 走动率 δ，单位 bin/符号；真实晶振 ppm 级差对应 δ~0.02 量级）——检测层的 δ 网与下游的斜率梯/fast 梯搜的都是它。

精度责任逐级下放：门扫 ±1000 样本 → 偏移筛查 ±256 → Stage-1 半 bin → CFO 精化 0.011 bin，每一级只把精度做到"下一级不嫌粗"的程度。

### 1.1 门扫：找到候选起点

沿时间轴每 512 样本滑动一个 NF 长窗（NF=4096，一个符号周期），逐窗做"乘参考下啁啾去斜 → FFT → 功率谱"。每张谱的判据是：取全谱**中位数**当作本窗的噪声底——去斜后信号能量只集中在峰附近一两根 bin，其余绝大多数 bin 里只有噪声，中位数就是噪声水平的稳健估计（峰的存在几乎不抬高中位数），不需要任何外部标定。若最大 bin 超过中位数 4 dB 以上，记一个尖峰（窗时刻， 峰所在 bin）。

**真前导时会出现什么**：前导是同一个啁啾波形按 NF 周期的重复。只要窗还落在前导跨度内，无论 512 步长滑到哪个相位，窗内都恰好含整一个周期，去斜结果是一个近单频音，幅度基本不随窗位置变化；音位由 CFO 决定，而 CFO 在前导期间恒定，所以连续各窗的谱峰落在**同一根 bin 附近**（抖动来自噪声与分数 bin，判据容差 4 bin），且窗窗持续超 4 dB。窗滑出前导边界（混入 SFD/后续符号）后，峰才衰减或跳位。

**纯噪声时**：个别窗也会偶然超 4 dB（谱极值统计的正常涨落），但峰的 bin 位置窗与窗之间独立随机、不持续。

按这个"持续性 + 频率一致性"差别，把相邻尖峰**时间间隔 ≤2 符号且 bin 位置变化 ≤4 bin** 的尖峰连成"事件"；事件起点取尖峰最密集的窗口起点（真前导的尖峰密集连续，孤立噪声尖峰连不成事件）。保留功率最强的 **top-3** 事件都送后续验证——单包场景下留 3 个不是为了多包，而是给粗定位留召回余量：个别 hop 窗可能因噪声起伏跌破 4 dB、或峰位抖出 4 bin 容差，同一条前导峰列会被拆成两截；噪声串出的假事件也可能在"总功率"这个粗排序上暂时领先。粗级只求不丢真起点、不求排对名次，真伪由带虚警控制的验证级裁决（代价只是两次额外筛查）。

### 1.2 偏移筛查：前导码粗对齐

这一步不产生新的"包在哪"假设，只精化门扫给的那个起点。门扫起点带着滑动步长（512）加尖峰分组的量化误差（约 ±1000 样本）；起点偏 Δ 意味着后面所有符号窗整体偏 Δ、跨到符号边界上，验证能量会白白损失。做法：在 ±1024 样本内试 5 个平移（步长 512），每个平移跑一个便宜版的相干得分（格网抽稀、只用来排序），取最高分的平移作为**胜点**。精度从 ±1000 磨到约 ±256（半个格距）。不再磨细的原因：两级验证对几百样本的残余错位不敏感（去斜音位对时移天然钝感、窗内仍含足够能量）；bin 级与亚采样级的精对齐不归检测层管——频域由 CFO 精化收口，时域由解码层的 Δ0/τ̂₀ 兜底。

### 1.3 Stage-1：非相干候选筛选（哪些频点值得看）

把 P 个前导窗放在胜点上，逐窗去斜 → 8192 点 FFT → 取中心 N=1024 bin 频带 → 功率谱；再把 P 张谱**非相干累加**成一张按 bin 的能量谱：

$$E(k)=\sum_{j=0}^{P-1}\left|X_j(k)\right|^2,\qquad k=0,\dots,2N-1$$

取能量最高的 16 个 bin 作为**候选 CFO**；bin 位置 k 对应粗 CFO 假设 $\hat\nu_c=(k-N)/2$（半 bin 粒度）。不做任何相干操作、不估任何参数——便宜，且对分数 bin/SFO 走动天然钝感（能量谱只认哪个 bin 站得高，不管相位长什么样）。

### 1.4 Stage-2：相干验证（这真的是包吗）

对每个候选频点 $\hat\nu_c$ 做一遍以下流程，逐个打分。

**量噪声底 $\hat\sigma^2$**：候选频点已告诉我们"信号可能站在哪几个频率上"；离这些频率很远的位置上就只剩噪声。对场内每个符号窗（前导/同步字/SFD 共 P+4.25 个，每窗单独去斜出谱），只取远离全部候选频点及其 SFD 镜像频点、并留出一圈护带（信号能量会漏到邻近格点）的频率格点，把功率平均得 $\hat\sigma^2$。作用：门限归一化用同一段数据自己的噪底，不假设噪声多大、也不用另拍一段"纯噪声"参考。

**两组验证**：A 组 = 前导 P 行 + 2 个同步字行（上啁啾族）；B 组 = 2.25 个 SFD 行（下啁啾族——其去斜音位按镜像律落在另一侧，验证时按镜像频率旋转，两组互为印证）。

**相干验证怎么做**：验证场由前导 P 行、两个同步字行、两个 SFD 整窗行和一个 SFD 四分之一窗行组成，共 P+4.25 个符号周期（后文称"行"）。每个符号行单独去斜出一张谱；验证要回答的是"这 P+4.25 行是不是一个自洽的前导"，所以关键在**行与行之间怎么联起来**：

- **分两组**。A 组 = 前导 + 同步字（同一符号族，去斜参考同向）；B 组 = SFD 行（下啁啾，用反向的参考去斜，音位因此落在"镜像"位置——由一条只依赖前导长度的几何关系从 $\hat\nu_c$ 算出，SFD 频偏在那附近再留 ±0.5 bin 小搜索域）。两组互相独立，**两边都出强峰才算证据**。
- **SFO 走动假设进每行的频率**。假设 SFO 走动率为 δ（bin/符号），则第 j 行的音位相对场心偏移"行号 × δ"（SFO 的时延逐符号累积 → 音位线性走动）；SFD 行参考反向，走动方向也相反。所以每个 δ 假设对应一套"每行取谱的频点表"。
- **组内跨行相干累加**。每个符号行去斜后，在频点表（候选频点 + 公共 CFO 粗调 + 已知偏移 + SFO 走动）指定的音位上各取一个复数值；把这些复数加权直接相加——相加前唯一的处理是给第 j 行乘一个相位坡 e^{−j2πκj}，坡的斜率 κ（真实 CFO 的小数部分）事先不知道，就把 256 个候选斜率全试一遍，哪种斜率下加出来的和最大就用哪种。实现上对这串复数做一次 256 点 FFT 即全部完成（1/4 行按 1/4 权）。最后只取和的幅度，各行共有的常数相位自动消掉——这也是 A/B 两组之间只能比幅度、不能复数相加的原因（两族参考的常数相位不同）。
- **两组之间只比幅度**。A、B 参考族不同、绝对相位不互校准，相加会互伤，所以两组各取累加幅度后相加（|A|+|B|）。

**打分与判决**：对每个候选频点，把上述过程在"公共 CFO 粗调（±0.25 bin，3 档，两组共用）× SFD 镜像频点微调（±0.5 bin，5 档）× SFO 走动率 δ（±0.10 步 0.01，21 档）× 公共小数 bin κ（256 点）"的小格网上跑一遍，取分数最高的组合；分数 = 两组幅度之和的平方，除以（本段噪底 × 相干行数 K_c=P+4.25）作归一。这些格网参数全部是被搜掉的干扰量，**不报给用户**——唯一附带输出的是取最大时的 δ 值（即 δ̂，交给下游当 SFO 走动中心）。最终把 16 个候选频点各自的最高分再取最大，与固定门限 **13.74 dB @ 虚警 1e-3**（无信号噪声池标定，跨 δ/前导长度单一门限）比较，过门即判定有包。

要点：**全场 P+4.25 个符号周期一行不浪费地进相干求和**（对上一代"拆分证书"路线的修正——拆行换理论性赔了 1 dB 能量）；固定变换族 + 解析门限意味着虚警可控可证（DeRa 式自适应搜索没有这个性质）；输出除"有没有包"外免费带出 δ̂，给下游斜率梯/fast 梯当中心。

*与传统前导相位差类方法的对比*（定位素材，详见 FINDINGS F13）：传统 CFO/STO 估计常在"跨符号同一个 bin"上测相位差，隐含 SFO=0——SFO 下 tone 逐符号走 δ bin，相邻行仅差 ≤0.1 bin，但整场累计 P·δ 达 1~3.6 bin，"同 bin"对应关系在整场尺度失效，且测得的相位差把 CFO 坡与走动混在一起（ν–τ 耦合）；要解耦得先假设 δ，形成循环依赖（测相位差要先知道对应 bin，知道 bin 要先知道 δ）。本设计把 δ 与相位坡都作为搜索维度联合边缘化（逐行频点表 + 行轴 FFT），不估不耦，且保住固定变换族的解析虚警性质。

### 1.5 CFO 精化（仓库名：连续锚）

过门之后，对胜出的那个候选频点在前导池化幅度谱上做抛物线插值，把 CFO 从 Stage-1 的半 bin 格点精度精化到 **0.011 bin** 的连续值 $\hat\nu$——这个精度是后续解码的生死线（分数 bin 差 0.15 就可能全灭）。这个精化值只作下游频旋用，不进检测统计量，所以门限校准不受它影响。

**本模块验证**：可部署形态下与 DeRa 检测器等虚警对比 +0.63~2.18 dB；链上体现为深端漏检率 0.5% vs DeRa 16.6%（δ=0，−24 dB 档）。

## 2. 时间基修复（M2，兜底主力：常规解码全败后才触发）

> **省流：M1 的四个输出 + 原始 IQ 进去，一个修复后的 IQ 出来。做法 = 假设 SFO 走动率 δ_c ∈ {0, ±0.01, ±0.02} 逐档做精确逆重采样，再用前导（码值公开）盲估剩余亚采样时延 τ̂₀ 并补掉——时间基回到整数格，然后交给解码器重试。全系统贡献最大的单个模块（δ=0.02 −24dB：PER .856→.204）。**

**要解决的问题**：真实时钟有偏差（ppm 级）时，信号在时间轴上被匀速拉伸——每个符号比上一个晚到一点点。这类伤害走的是**相位通道**：折叠点位置漂移 + 两段 sub 信号的相对相位失配 + 亚采样时延，斜率梯这类"调音位"的手段修不了。

**做法**（每档候选参数做一遍，CRC 通过即停）：两刀各付各的账——**重采样修 SFO，τ̂₀ 修的是修完 SFO 之后剩下来的常数 STO**。顺序不能反：有 SFO 时时延逐符号变化（τ(t)=τ₀−εt），单次时延补不平；先修速率把它归约成常数，STO 才能一次分数时延补掉（(ε, τ₀) 两参数问题被严格归约为纯 STO 单参数问题）。

**精确逆重采样**。假设 SFO 走动率 $\delta_c\in\{0,\pm 0.01,\pm 0.02\}$（bin/符号），对整段 IQ 做该假设下的精确逆时间变换

$$y[m]=x\!\left(o+(m-o)(1+\varepsilon_u)\right),\qquad \varepsilon_u=-\frac{\varepsilon}{1+\varepsilon}$$

（17 抽头 sinc 插值；注入模型本身精确可逆，$\varepsilon_u$ 是精确逆而非近似 $-\varepsilon$）。

**前导盲估 $\hat\tau_0$**。剩余的亚采样时延用前导码估——前导码值公开（恒为 0），无需任何先验：在全前导窗上做逐样本精确模板相关，一维格搜索

$$\hat\tau_0=\arg\max_{\tau}\ \sum_k\frac{\left|Z_k(\tau)\right|^2}{M_k}$$

**分数时延对齐**后，整条时间基回到整数格——折叠点回到解码器假设的位置，两段 sub 信号自然同相。

**为什么有效**：修复后解码器看到的就是"教科书对齐"的信号，两段合并近无损（实测修复后统计量与完整模板相关器之差 ≤0.2 dB）。**验证**：这是全系统**贡献最大的单个模块**——δ=0.02、−24 dB 档把 PER 从 .856 拉到 .204（.652）；机制级对斜率梯 11 倍差。

**一个诚实注记**：深端赢家常常是"半修复"参数对（如 δ_c=0.01 配某个 τ̂₀）而非真值——CRC 仲裁的是**参数对**的解码可行性，不承诺参数收敛到真值。这是架构特性不是缺陷：错误候选撞过 16 bit CRC 的概率约 $2^{-16}$/候选，可忽略。

## 3. 常规解码与仲裁（M3，检测通过后先执行这一步）

> **省流：M1 输出 + 原始 IQ 进去，一个判决载荷出来。流程 = 频率居中（按 δ̂）→ 斜率梯反走动（4 档预旋）→ 两路解码器（A=两段参考+公共相位相干合并；B=κ 格 trellis 走格）→ 7 个整数 bin 偏移 × CRC 逐级早退。仲裁是正确性层不是增益项：吸收 bin 约定差/参数简并/边际判决，拆掉则全档全灭。**

**要解决的问题**：多数包不需要动时间基，用对齐-解码-仲裁的常规链就够；且要有一个"永不比单解码器差"的兜底结构。

**为什么两路解码器**：每个包用两个**结构不同、死法不同**的解码器各解一遍，CRC 仲裁谁先过就用谁。解码器 A（逐符号、按候选折叠位置切两段相干合并）平均最强，但死穴是折叠位置假设错（SFO 漂移）时合并崩；解码器 B（整条轨迹、κ 假设格上 trellis 走格）不追折叠位置，恰好在 A 死的那类包上活。实测定律：同结构重试堆数量无用，只有结构性分集才兑换成 PER。

**解码器 A（收编 DeRa 解码器结构）**：对每个符号窗按**该候选自己的折叠位置**切成两段分别投影（回绕参考），用一个**全帧公共的单个相位标量**做闭式 ML 估计后相干合并两段：

$$\hat\varphi_0=\angle\sum_i T_iF_i^{\,*},\qquad \text{行}_k=\left|F_k+e^{-j\hat\varphi_0}T_k\right|^2$$

两个实测要点：折叠处的频率跳变在过采样下会把单 FFT 能量劈进两个混叠 bin——两段参考滚动是**必需结构**不是优化项；公共相位标量是解码器里最大的单部件（拆掉它连干净信号都有 14% 的帧失败）。

**解码器 B（自有）**：把符号窗按 4 个相位抽取成 chip 序列、在 κ 假设格（±0.5 bin 内 5 档）上做能量谱，trellis 在 κ-时间维上**走格而不估计**——SFO 走动被边缘化而不是被追踪，与解码器 A 形成结构分集。

**CRC 逐级仲裁**：7 个整数 bin 偏移（Δ0）× 解码器顺序逐级早退（预算 56 次判决 vs DeRa 25 次）。仲裁不是增益项而是**正确性层**：它吸收整数 bin 约定差、参数对简并、边际判决——拆掉它（单判）任何链全档全灭。

**相位精化 P（解码器 A 之上的精化件）**：把公共相位升级为逐符号斜坡 $\varphi_k=\hat\varphi_0+s\,(k-k_c)$（斜率 s 由强符号加权拟合，护栏失败自动退回常数）。实测贡献 +0.007 PER——段内相位通道已到数学上限，作为负结果保留。

**验证**：解码器 B 的结构分集 +.019（常规链层）；解码器 A 内相干合并 +.40 PER（−24 档，对比非相干度量）；斜率梯 +.084；相位精化 P +.007。
