## 0. 两個关键修正（用户计算）

1. **段内曲率不是主菜**：中点频率对准后，残余二次相位 A(t−m)² 的相干
   功率损失 ≈ **0.0045 dB**（AT²=0.43、整符号长最保守）——与 D2F m3p2
   梯内残差分析（≤0.005 斜率 → ≤0.1dB）互证。"消掉 DeRa 剩余斜率就能
   明显增强"的预期作废。
2. **合并必须连噪声一起算**：若实现是"两个整窗 FFT bin 旋转相加"，
   两支各含整窗噪声 → 信号幅度同、噪声方差 ×2 = **3.01 dB 损失**（SF7/os4
   等长理想例；是数学示例，DeRa 实码未读不能认定）。正确统计量
   Z = q^H C_w^{-1} r。**D2F port 已核实无此问题**：`_wrap_split_matrices`
   零填充切分，每样本恰用一次（见 §3 实验一）。

## 1. 完整波形模型（含回绕与累计误差）

回绕时刻 u_w(c)=T(1−c/N)；理想符号相位

  φ_c(u) = 2π[(−B/2+c/T)u + (B/2T)u² − B(u−u_w(c))₊]

频率在回绕处跳 B、**相位连续**——两段相位关系由模型完整确定，无需经验跳变角。
（工程核对：gr-lora build_upchirp 的 fold=(N−c)·os 分段线性公式与之等价，
D2F ref_template 按此实现。）

时间映射 g(t)=(1+ε₀)t − τ₀ + ½ε̇t²（ε 同源时钟关系作先验不锁死）；
载波 θ(t)=2πf₀t+πḟt²+ψ(t)；r(t)=h·e^{jθ}·e^{jφ_{c_k}(g(t)−kT)}+w。
一个模型同时含：符号时长变化、斜率变化、回绕位置变化、初始/累计 STO、
跨符号 CFO 相位、慢相位。

## 2. 接收五步

1. **前导参数分布**：η=(f₀,τ₀,ε₀) 三核心参数 + 不确定度与**参数相关性**
   （CFO-STO 近简并时保留多条假设路径，交给 payload 淘汰）——区别于
   DeRa 的"只加候选数"：候选被 payload 持续更新。
2. **逐样本完整模板相关**：Z_k(c;η)=Σ_{n∈I_k} r[n]q*_{k,c}[n;η]，
   q=e^{jθ̂}e^{jφ_c(ĝ−kT)}——段内弯曲/两段回绕相位/分数 CFO 泄漏/STO
   累计/跨符号相位一次进模板；"不需要先提平均频率再指望一个旋转补好"。
   计算大时先 FFT/Savaux 筛码值再精相关，**必须测量正确码值被筛掉的概率**；
   分数重采样版 vs 原始采样精确版不得重复补偿同一项。
3. **跨符号块跟踪 + 前后向平滑**：τ_{k+1}≈τ_k−ε_kΔt_k；
   φ_{k+1}≈φ_k+2πf_kΔt_k+πḟΔt_k²。量级：SF12 残余 1ppm×100 符 ≈0.41chip；
   残余 1Hz CFO ×100 符 ≈20.6rad 公共相位——**比段内弯曲大得多**。
   块长按相位稳定性自适应；不在弱符号上自由估相位。
4. **相位不确定度加权判决**：Λ_k(c)=log∫p_k(φ)exp[(2aRe{e^{-jφ}Z}−a²E)/σ²]dφ
   ——确定→实部投影、未知→幅度、部分可信→自然过渡；**不同同步假设在
   似然层合并，不得直接加复数**。
5. **软解码反馈**：保留 p_k(c)，译码软信息反馈参数估计
   η_new=argmax Σ p_k(c)log p(r_k|c,η)+log p(η)——可信符号多贡献、
   模糊符号多解释；外信息交换防重复计数；CRC 只作终验。

## 3b. 行1/2 结果（ref_template.py，3 帧 P=8/8/16，真值码值+干净信号估计参数）

**行1（native，真值参数）**：full−port = **−0.8 ~ −3.2 dB**——port 的
ML φ̂0 相位自适应略胜开环模板；归因 = τ0（sub-sample STO，实测
帧级 ≈2.15/−1.15/2.25 采样，f9 撞估计边界）必须进估计环，开环模板
τ0 差 ~1 采样 → 段间相对相位差 2π·Δτ/4 ≈ 1.6 rad → 1~3dB。**设计
结论：τ0/段间相对相位必须在线估计（小梯或进 η 联合精化），不能定死。**
顺带：段内曲率证实 ~0.0045dB（用户计算 ✓）；模板实现抓出三个约定坑
（码值 +1 约定、载波坡符号、τ0 项缺失——都是 Eq.20/21 的具体形态）。

**行2（δ=0.02 注入，GT ε/τ0̂）**：
- vs 裸 port：**+3.2 ~ +5.9 dB**（中位，逐符号统计量 SNR）；
- **vs port+最佳梯斜率（=现行 D2F 链的最强形态）：+1.1 ~ +4.8 dB 剩余空间**
  ——斜率梯只修音位走动，修不了 wrap 边界位置漂移 + TO 相位 + 段内
  伸缩弯曲的组合，与用户预判一致（边界漂移/错误合并 >> 曲率）。

**结论：精确模板接收机在漂移域有实测 1~5dB 统计量级余量**，是
D2F 下一步的正当升级方向；快实现路径 = 每候选 ε 分数重采样 → 常规
dechirp-FFT（须对照本参考实现验证无损、防重复补偿）。行3-5 待做。

记录维度：误差 × 符号位置 × 码值 c/N × 包长 × 残余 SFO；前后向平滑延迟、
候选搜索算力与 PRR 同报。
