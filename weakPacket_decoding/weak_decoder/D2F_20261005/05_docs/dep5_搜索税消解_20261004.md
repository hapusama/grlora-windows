# dep5 设计——搜索税消解版可部署检测器（2026-10-04 夜，用户令"强化方法"）

> 背景裁定（用户 2026-10-04 定死）：**依赖网格的路线不再继续打磨**——
> dep4(+0.63~+2.18) 是网格路线的顶点，但格点对齐审计风险 + §5A 新规
> （检测验收=下游 CRC）+ 行-证书不相容律（"进一步突破需消解搜索税
> 本身，不是再加行"）三者合围，网格路线的边际收益已尽。
> dep5 = 把 dep4 验证级里每个**被搜索的维度**逐个替换为**已验证的
> 解析原语**，目标：门限税从 3.46dB 压到 ≤2dB，δ 连续覆盖（结构性
> 免疫"压格点"审计），输出高精度 (ν̂,κ̂,δ̂) 供 E2E 锚。

## 2. 架构（两级，全场 12.0 行）

**Stage-1 提名**（复用 m2c.nominate，P 行能量列图 top-K，K 预注册）
+ Jacobsen/抛物线精化：p = Re[(X[k−1]−X[k+1])/(2X[k]−X[k−1]−X[k+1])]
在池化幅度谱上 → 连续 ν̂ = (col+p−N)/2（目标 ±0.05 bin；超差回退
迷你 bank {−0.125,0,+0.125}，smoke 判定）。

**Stage-2 验证（keystone 核，d1 验证版移植 + m2c 约定）**：
- 场 = 前导 + 2 sync + 2 SFD 整窗（**1/4 窗弃**，K_ks=12.0@P8，
  d1 keystone 先例：低列 κ 残余放大区）；
- 行去斜：A 行 e^{−2πi(ν̂+o_j)n/NF}；B 行（SFD，m2c 无共轭约定）
  e^{−2πi(ν̂+sfd_c)n/NF}，sfd_c=镜像律中心；
- **剪切**：T(q,κ_h) = Σ_n Σ_j √b_j e^{−2πiκ_h e_j} Y[j,n]
  e^{−2πi q e_j n/(N_FINE·NF)}，e_j = sgn_j·idx_j（SFD 行走动反号，
  m2c 约定）；q 轴 256 点 = **连续 δ ∈ (−0.5,0.5]**，无格点；
- κ = 两段自适应 bank（粗 1/16 ×16 → 细 1/128 ±1/4 ×65，d1 原样，
  细级量化损失 ≤0.1dB 的先决条件）；
- score = max_{q,κ_h}|T|²/(σ̂²·K_ks)；σ̂² = m2c 远子格护带式
  （护带同时罩直接簇+镜像簇）；
- 输出 (ν̂,κ̂,δ̂=q̂/N_FINE 环绕中心) —— 供 M3 E2E 锚。

**门限双报**（cert8 惯例）：解析参考 = cfar_threshold(FAR, c_q·κ_eff·K)
（c_q = C.upcrossing_c 上穿闭式，1D 验证 0.01%@1e-2；两段 bank 声明为
近界）；**部署 = 该臂经验 H0 池化精确分位**（协议 Tier3 同 dep4/dera）。

## 3. 预注册实验 C 口径（协议 v1.1 §5A 全条款）

1. 数据：真实 OTA 28 帧 + d2_core.resample_sfo 注入 + 合成 AWGN 至
   −26~−38dB；H0 = 合成 AWGN（声明；FF 真实噪底 H0 列为交叉验证项）。
2. **δ 列表（含半格点/尴尬值，回应审计）**：{0, 0.005, 0.01, 0.015,
   0.02, 0.025, 0.04, 0.082, 0.087}——0.015/0.025/0.087 为 dep4 未测
   的格点外值，dep5 结构免疫但照测；0.082/0.087 标"压力档"
   （超 A3 实测界 0.024 三倍+）。
3. 臂：dep5(K主档)+dep5(K16 嵌套消融)+dep4k16(join)+cert-q(oracle
   标签)+dera(port 原样)；门限=各臂自己 H0 分位，FAR=1e-3。
4. 指标：Pd=0.9 交点 + 配对 w/l + **K 召回@−34 + |ν̂−ν_GT|、|δ̂−δ|
   误差分布**（§5A 中间层）。
5. **胜负判定归 §5A：本实验只出诊断表；验收 = dep5k 接 M3 全链
   CRC 终判**（dep4k16 同跑对照）。
6. 杀死判据（预注册）：dep5 门限 >13.2dB；或任一 δ 档 Pd09 交点劣于
   dep4k16 >0.2dB；或 keystone-网格偏差 OTA >0.3dB；或 Jacobsen 锚
   |误差|>0.15 bin 占比 >5%@−32 → 回滚"dep4+半格点补考"路线。
