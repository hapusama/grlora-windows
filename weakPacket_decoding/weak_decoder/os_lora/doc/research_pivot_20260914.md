# LoRa 研究方向重审与本轮验证（2026-09-14）

**判断：旧的“重排过采样分支即可增强弱包”主张不宜继续作为论文核心。当前值得优先验证的是：把已有编码约束纳入低采样接收，研究哪些包仍可唯一恢复，以及为此付出多少噪声与计算代价。已经有真实 IQ 的可行性证据，但还没有得到足以承诺投稿的完整结果。**

这次的目标是判断研究问题是否成立，而不是把接收脚本修好后称为“复活”。用户允许调整到低采样、干扰或多包联合接收。本轮实际实现并运行了四个可行性脚本；保留了失败方案和修正后的结论。

**为什么停止原来的主张。** 9 月 11 日的实验审计已经发现：同一批观测的多相重排不自动产生独立分集；在带限噪声下，增加过采样分支未带来相应的捕获收益；复杂鲁棒残差方法在人工脉冲下又输给简单裁剪或置零。9 月 13 日的残余频偏恢复在新一轮 72 个条件下由 46 次变为 48 次成功，在自然弱包上主要减少搜索次数。这些是有用的工程结果，支撑不了原先期待的通用弱信号创新。

历史证据见 [9 月 11 日审计](../../../data/experiments/paper_audit_20260911/REPORT.md) 和 [残余频偏实验](residual_cfo_revival_20260913.md)。不建议再靠增加网络层数、分支权重或 CRC 搜索次数延续同一主张。

**本轮发现：符号有混叠，不等于编码后的整块数据不可恢复。**

SF10、BW125 kHz 的每个符号，在复采样率 BW 下有 1024 点。均匀保留一半后，单符号 FFT 只能区分 512 个余数；直接选其中一个完整符号，会丢掉另一个候选。LoRa 的 Hamming 编码、对角交织和逆 Gray 映射把不同符号联系起来。把这些关系写成 GF(2) 线性约束后，本轮 SF10/CR1 配置的一整个交织块能够唯一恢复。

在三个已有真实采集文件、共 28 个包上，512 点联合解码恢复了 **28/28** 个完整载荷，包含从保留观测重新解码 header，CRC 通过且载荷逐字节匹配干净参考。相同 512 点的直接逐符号硬判决为 **0/28**。

这是对旧的低采样基线的纠正。**不能把 0 到 28 当成相对现有最佳方法的论文增益。** 本实验仍由干净接收提供每个符号的窗口起点、频偏、LDRO 和帧范围，没有实现低采样率发现未知到达的包。

**加噪后，减少样点的代价仍然存在。**

下表采用相同噪声观测配对，双方使用每符号 Top-2 候选及精确块编码约束。CRC 只用于最终验收，没有参与候选挑选。噪声是在 BW 复采样网格上的独立复高斯噪声；表中的 RGR 是采集信号功率与新增噪声功率之比，采集信号包含原有噪声，因此不是标定后的空口 SNR。

| 条件 | 1024 点联合解码 | 512 点联合解码 |
|---|---:|---:|
| 原始 IQ | 28/28 | 28/28 |
| RGR −7 dB | 84/84 | 84/84 |
| RGR −10 dB | 84/84 | 81/84 |
| RGR −13 dB | 81/84 | 73/84 |
| RGR −16 dB | 74/84 | 3/84 |

每个加噪点是同 28 个包的 3 个随机种子，不是 84 个独立空口包。这些点说明性能有明显损失；网格较粗，不能据此发布精确的灵敏度损失数值，更不能声称省一半样点而没有代价。

**一个实际被否定的改法：均匀骨架加少量额外样点。**

本轮还实现了 256 个均匀点加 16 个固定补充点。先用余数及编码筛出整块候选，再用保留的样点给候选打分。SF10/CR1 的四倍抽取在每块留下 4 个自由比特，因此一个确定的余数组合对应 16 个合法块；程序也保留 Top-2 余数形成的多个组合。

同轮比较采用共同的 1024 点实解码 header、相同噪声、新的固定种子。随机 272 点基线完整计算所有 1024 个符号分数，并使用相同类型的块约束解码。它不是只做硬判决的弱对照。

| 条件 | 随机 272 点＋块解码 | 均匀 256＋16 点＋整块候选 |
|---|---:|---:|
| 原始 IQ | 28/28 | 28/28 |
| RGR −7 dB | 81/84 | 74/84 |
| RGR −10 dB | 78/84 | 38/84 |
| RGR −13 dB | 2/84 | 0/84 |

该固定补充点方案未过性能关。数据不支持继续把它包装成新接收器。它也说明：无噪声下能补齐秩，不代表能在噪声下可靠区分候选。现阶段没有测出完整接收器的计算或能耗优势。

**更完整的研究问题：编码、包长和采样率共同决定剩余歧义。**

除了块内 Hamming，整包 CRC 也约束有效载荷。固定帧配置时，可以把整个编码链写成

`z = A_p u ⊕ A_t t ⊕ b`。

其中 `u` 是载荷比特，`t` 是未知填充，`z` 是低采样解调保留的余数比特，`b` 包括固定 header 与白化偏置。对这个模型，载荷唯一恢复的充要条件是

`rank([A_p A_t]) − rank(A_t) = 8 × payload_length`。

这里说的是理想同步、采用余数观测的有限码模型；不是任意模拟接收器的采样定理。硬件波形畸变、符号间相位信息及其他先验不在这个模型里。

填充必须单独处理。本轮回编码核查发现，28 个真实包的最后 5 个符号都与默认零填充编码器不同，共 140 处；把解出的填充作为未知的合法编码内容处理后，28 个包的全部观测均匹配。这推翻了直接把零填充当成已知量的分析前提。

对 SF10、CR1、CRC 开启、`grlora` CRC 约定、四倍均匀抽取，修正后的计算如下。这里只列实际检查的长度，不把离散检查说成覆盖所有长度的定理。

| 载荷字节数 | 假设已知零填充时的歧义比特 | 填充未知时的载荷歧义比特 |
|---:|---:|---:|
| 4 | 0 | 0 |
| 8 | 0 | 0 |
| 12 | 0 | 0 |
| 16 | 0 | 1 |
| 20 | 1 | 3 |
| 24 | 3 | 5 |
| 28 | 7 | 8 |
| 33 | 11 | 12 |

4/8/12 字节的结果支持进一步做短包验证；33 字节的结果说明，这个余数模型里，即使纳入 CRC 仍不能唯一确定载荷。脚本保存了两个不同载荷及相应填充产生同一余数观测的具体反例。SF7、SF12 和两种本地 CRC 约定也分别计算，不能把上表直接推广过去。

102 个配置各做了 16 次随机完整帧检查，共 **1632 次仿射关系检查**，满秩时还实际解回原始随机载荷。它们是数字编码实验，短包的四倍降采样尚无本轮空口结果。如果 CRC 被用于内部解码，CRC 通过就不能再作为独立的正确性证据；后续必须用独立发射日志核对字节并测未检出错误。

**与已有论文的关系，必须先讲清楚。**

- 低采样 LoRa 本身已有 LiteNap。其方法利用硬件相位抖动及频率泄漏形成的指纹解除混叠，还包含检测与同步。因此“低于某个采样率也能收到包”不是足够的新颖性。当前可检验的区别是编码约束的恢复边界及其实现，不依赖提取硬件指纹。[LiteNap 作者机构页面](https://research.polyu.edu.hk/en/publications/litenap-downclocking-lora-reception-2/)
- 联合解调与 Hamming 译码也已有工作。例如 2025 年的 Bayesian IDD 在解调器、译码器和信道估计之间交换软信息。“做联合解码”本身同样不是新贡献。[IEICE 原文](https://globals.ieice.org/en_transactions/communications/10.23919/transcom.2024EBP3070/_f)
- 项目已有 Sym-FEC 风格基线，但其 README 明确说明并非作者完整复现。后续必须核对 Sym-FEC 正文，不能以击败这份近似实现宣称超过该论文。[本地基线范围](../../baselines/symfec/README.md)
- 多包相干合并已有 XCopy 和 B²LoRa。B²LoRa 的实验明确关闭会让重传载荷变化的时间戳、计数器调试元数据。这提示“载荷部分变化时的联合接收”可以作备选问题，但需要真实共享内容及独立变动字段的证据，不能直接套用到加密后内容不同的 LoRaWAN 帧。[B²LoRa 原文第 4.1 节](https://arxiv.org/html/2505.24140v1#S4.SS1)

以上检索确定了必须跨过的已有工作；没有证明新问题尚无人做过。

**建议把下一阶段限定为三个有终止条件的研究关口。**

1. **先确认边界是否是可发表的新知识。** 扩展并推导 SF/CR/LDRO/包长/未知填充下的秩与距离，而非只画几张仿真曲线；核对 LiteNap、Sym-FEC 和编码 LoRa 文献。若已有论文给出相同结果、相同接收机制，停止把它作为创新主线。
2. **做短包的真实接收验证。** 固定 4/8/12/16/33 字节、至少两次独立采集、随机载荷及发射日志；同时记录硬件、带宽、SF、CR、CRC、采样与前端滤波。先核对模型，再比较同一观测、同一同步先验下的软译码、联合译码和 LiteNap 类方法。若收益只存在于错误的零填充假设或弱硬判决基线，停止。
3. **证明真实资源收益。** 逐步移除干净定位和频偏先验，测连续流 CRC 正确率、误接受率、每包处理时间、内存与观测量；若目标是省电，加入实际硬件测量。在相同可靠性下不能降低实际资源成本，或同步开销吃掉全部收益，则不把它写成低成本接收系统。

优先级是短包的编码约束与均匀低采样。原来的真实 IQ、同步链、FEC/CRC 和实验工具可以继续用；“虚拟多天线普遍提升弱包”的主张应退出论文。部分变化载荷的多包接收作为备选，暂不同时铺开两个大系统。
