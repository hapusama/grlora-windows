# Sionna RT Aligned LoRa SER Study

This directory connects the hospital IFC model to the existing weak LoRa
demodulator and evaluates symbol error rate (SER) under ray-traced propagation.
The first experiment intentionally assumes perfect target symbol boundaries and
zero target CFO so that synchronization failures do not hide demodulator
behavior.

## Pipeline

1. `convert_ifc_scene.py` converts `Buildings/B/DeKH_B_ICU.ifc` into three
   material-grouped PLY meshes and a Sionna RT scene.
2. `generate_cirs.py` traces the target and two interferer links at 487.7 MHz.
3. `run_aligned_ser.py` generates LoRa symbols, propagates each transmitter
   through its own CIR, adds receiver thermal noise, and compares the existing
   Savaux, fixed-pattern, GLS, wrap-consistency, and conditional detectors.

Sionna RT produces deterministic paths, not receiver noise. The SER runner uses
white complex receiver-input noise scaled so that the shared front-end FIR has
output power `k*T*BW*NF`. The target, interference, and noise all pass through
the same delay-compensated 125 kHz receiver filter. Interference is generated by
asynchronous same-SF LoRa transmitters with independent symbols, timing offsets,
CFOs, and ray-traced channels. No arbitrary covariance matrix or hand-selected
colored-noise process is injected.

## Reproduction

Run these commands from `weakPacket_decoding` in PowerShell:

```powershell
conda run -n sionna-hospital python weak_decoder/rt_sim/convert_ifc_scene.py
conda run -n sionna-hospital python weak_decoder/rt_sim/generate_cirs.py --samples-per-source 100000

$env:PYTHONPATH = (Get-Location).Path
conda run -n gr-lora python weak_decoder/rt_sim/run_aligned_ser.py `
  --symbols 200 `
  --trials 3 `
  --target-tx-dbm=-63,-65,-67 `
  --interferer-tx-dbm=-78.5 `
  --scenarios thermal_only,one_interferer,two_interferers `
  --output data/sionna_rt/final/aligned_ser_final_487p7
```

The final directory contains per-symbol decisions, per-trial metrics, the
per-condition and cross-scenario aggregate CSVs, metadata, and the SER plot.
See `data/sionna_rt/README.md` for the run inventory and artifact definitions.

## Environments Used

The recorded final run used two Conda environments:

- `sionna-hospital`: Python 3.12.13, Sionna RT 2.0.1, Mitsuba 3.8.0,
  Dr.Jit 1.3.1, IfcOpenShell 0.8.5, Trimesh 4.12.2, NumPy 2.5.1.
- `gr-lora`: Python 3.10.20, NumPy 1.26.4, Matplotlib 3.8.4.

`convert_ifc_scene.py` and `generate_cirs.py` run in `sionna-hospital`;
`run_aligned_ser.py` runs in `gr-lora` and imports the existing weak-decoder
implementation directly.

## Fixed Pattern Bank

The current eight-pattern order is recorded explicitly because the original
`compact96_final_full/selection.csv` artifact is not present in this workspace:

```text
multiscale_w32_s1_b1
multiscale_w32_s1_b0
multiscale_w32_s1_b2
multiscale_w32_s1_b3
block_w2_s3_b3
block_w8_s1_b0
block_w32_s1_b3
multiscale_w2_s3_b3
```

For this aligned, narrowband target link, the measured correct-bin responses of
these patterns are effectively equal: the peak-to-peak amplitude spread is
`0.0447 dB`, the phase spread is `0.2167 degrees`, and the RMS relative error
from an all-ones steering vector is `0.00179`. Thus `a` proportional to the
all-ones vector is valid for this specific experiment; it should be measured
again when synchronization, hardware, or bandwidth changes.

## Current Result

Each point contains 600 aligned SF10 symbols. Across all six interferer points
(3600 symbols), the aggregate SER is:

| Detector | SER | Relative error change vs Savaux |
| --- | ---: | ---: |
| Savaux | 0.4803 | baseline |
| Equal 8 patterns | 0.4836 | 0.69% worse |
| Equal 8 + wrap consistency | 0.4197 | 12.61% fewer errors |
| Direct GLS, no wrap | 0.4819 | 0.35% worse |
| CG GLS, no wrap | 0.4814 | 0.23% worse |
| CG GLS + wrap consistency | 0.4167 | 13.24% fewer errors |
| Conditional GLS | 0.4317 | 10.12% fewer errors |

The main reduction comes from LoRa wrap consistency. Adding wrap consistency to
equal weights reduces errors by 13.21%, while replacing equal weights with GLS
after wrap consistency reduces them by only another 0.73%. Against Savaux, the
paired counts are 248 fixes and 19 breaks for CG GLS + wrap, but only 55 fixes
and 61 breaks for direct GLS. Thermal-only trials show no gain: Savaux SER is
0.0517 versus 0.0583 for CG GLS + wrap.

Therefore this experiment supports the usefulness of nonuniform observations
plus LoRa wrap structure under structured LoRa interference. It does not yet
support the stronger claim that GLS covariance weighting is the source of the
gain.

## Limitations

- Target timing and CFO are ideal. Full preamble detection, frame synchronization,
  header decoding, and packet FER are not included yet.
- This is one IFC geometry and one set of transmitter/receiver placements.
- The current interferers use fixed timing offsets and CFOs; target SIR spans
  roughly -2.6 dB to -7.0 dB. Timing, CFO, SIR, position, and interference type
  still need systematic sweeps.
- At 125 kHz, the target CIR delay span is only about 22 ns, far below the 2 us
  oversampled sample period. The channel is effectively narrowband/flat rather
  than strongly frequency selective.
- Concrete material parameters are extrapolated below the ITU model's documented
  1 GHz lower bound. Absolute path loss needs measurement calibration.
- The conditional branch-color threshold `0.107121` was calibrated for the old
  noise model. The band-limited receiver noise produces a mismatch near `1.28`,
  so the gate must be recalibrated before its result is treated as deployable.
  More importantly, the observed 95th percentiles are `1.2964` for thermal-only,
  `1.2969` for one interferer, and `1.2974` for two interferers. Their near-total
  overlap means that merely replacing the scalar threshold is unlikely to make
  this feature a useful collision detector under the current receiver model.
- More symbols, placements, interference types, and paired confidence tests are
  needed before making a final performance claim.
