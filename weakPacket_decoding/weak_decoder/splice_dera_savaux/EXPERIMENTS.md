## E3. δ 记账勘误（2026-10-05，debug_gap/gap2.log，用户质疑触发）

**问题**：同数据集同先验，实验B SAVAUX@−26=.421 vs 本战 PRIOR@−26=.511。

**A/B 归因**（同噪声段，只换记账/窗口/种子）：

| 变体 @−26 | SER | 差异来源 |
|---|---|---|
| A CRC 仲裁（失败回退 δ=0，本战记账） | .5112 | 复现 checkpoint ✓ |
| B 逐帧冻结 δ_clean（实验B记账） | **.4248** | ≈ 实验B .421 ✓ |
| C +battle SNR 窗 | .4364 | 窗口 +.01 |
| D +battle 种子常数 | .4357 | 种子 ≈0 |

缺口 +0.086 **全部**来自 6 个 δ_clean=1 的帧：深端 CRC 全失败 → 回退
δ=0 → 整帧 35 符号全记错（errA≈104 vs 冻结 δ 的 27~68，+254/2940）。
**物理上 Savaux 未变差；对齐记账后逐位级吻合。**
教训：实验A式与实验B式 SER **不可直接互比**（记账规则不同）；横比须同记账。

## E6. v2/v3 会战（2026-10-05 autoresearch：fd×γ-链，工作区双指标首胜全 DeRa）

三 agent 并行（竞争者/技术文献 + 失败分类学）+ 两轮验证 + 两场全量战：

- **失败分类学**（analysis/TAXONOMY.md，252 单元与原实验 0 失配）：
  v1 剩余失败三分 = 检测硬地板 16 / fd 选点失误 13-14 / FEC 边缘 30；

  检测器 236/252 单元只回 1 候选（top-5 从未实际展开）。
- **机制否证**（validate_v2/v2b）：整数谱重权式 κ 格（SAVK）与相干度
  判据双双失败——混跳区是 wrap 边界**时域**错位，频域不可修，fd 不可
  替代；SAVK2（支路时域旋转）收窄混跳区但带 max 税，弃。
- **v2**（dera_fd_gamma_20261005）：DERAfd×GAMMA 工作区双指标首胜全
  DeRa（−20 PER .000 vs .024；−22 .060 vs .107），−24 SER 反转暴露 fd
  能量判据深端缺陷。
- **v3 判据**（validate_v3）：前导相干模板（真 upchirp×8 符号×合并谱×
  FFT-max 相干积累）在 14 个失误单元 14/14 改善（均 SER .420→.135）、
  native 零回归。
- **v3 全量**（dera_fdc_gamma_20261005）：**DERAfdc×GAMMA 工作区每档
  双指标全胜**（−20 .003/.000 vs .014/.024；−22 .011/.060 vs .033/.107），
