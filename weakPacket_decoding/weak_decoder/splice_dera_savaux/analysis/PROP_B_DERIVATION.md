# 命题 B：序列网格时延跟踪 vs 一次性时延估计的增益条件

## 0. 记号与 SNR 换算（自包含）

- SF=10，N=1024，OS=4，N_fft = N·OS = 4096，M = N = 1024，N_sym = 35，前导 P = 8。
- 时延 d[n] = d₀ + εn，ε = 0.01 样本/符号（OS 速率下；下证 **1 个 OS 样本时延 ⇔ 恰好 1 个 bin**：dechirp 后残余单音频率 f = μτ，μ = BW²/N，τ = κ/(OS·BW) ⇒ f = κ·BW/N = κ·Δf_bin）。故残余错位 κ（样本）= 分数 bin 偏移，核损失取 Dirichlet 极限
  Λ(κ) = |D_{N_fft}(κ)|² = [sin(πκ)/(N_fft·sin(πκ/N_fft))]² → **sinc²(κ)**, κ∈[−1,1]. (1)
- **每符号发射 SNR ρ**：设 SNR_pkt 为在采样复带宽 B_s = OS·BW = 4BW 内测得的整包 SNR。dechirp+4096 点 FFT 是对 chirp 的匹配滤波，峰值 bin SNR = E_s/N₀，而 E_s/N₀ = N·OS·SNR_pkt：
  **ρ = SNR_pkt + 10log₁₀(N·OS) = SNR_pkt + 36.1 dB.** (2)
  （若 SNR 以信号带宽 BW 而非 OS·BW 为参考，则 ρ = SNR + 30.1 dB：OS 只增加噪声带宽、不增加信号增益，这就是 (2) 中"除不除 OS"的全部含义。ρ 是**每符号**量，无 N_sym 增益；包长只在 C1 中以 1/N_sym 进入。）
- 噪声主导的谱峰：max of L = N_fft 个独立 Exp(1) bin 功率 ⇒ log 域 Gumbel：μ_G ≈ ln L + γ_E = 8.90，σ_G² = π²/6 = 1.64。**ln L = 8.32 是发射"有意义性"阈值**。
- M 进制非相干（|C|² 判决）SER 标准大 M 近似：
  **P_M(γ) = 1 − exp[−(M−1)·½·e^{−γ/2}]**, γ = ρΛ. (3)

## 1. 一次性（baseline）分析

**(i) 前导估计误差。** P 个前导符号功率积累后峰 SNR ρ_pre = Pρ（+9 dB）。常识性结论（Rife–Boorstyn 型周期图峰定位）：(a) 无野值区，分数位置的 CRB 由核宽与 RMS 带宽决定，对平坦分数带谱（β̃² = 1/12）σ_η ≈ 0.55/√(Pρ) 样本；(b) 野值阈：任一纯噪声 bin 超过信号 bin 之概率 ≈ ½e^{−ρ_pre/2}，故
P_out ≈ (L/2)·e^{−Pρ/2}, 阈值 ρ_pre ≈ 2ln(L/2) ≈ 11.5 dB. (4)
本区间 ρ_pre = 8ρ ∈ [82, 206]（≥19 dB）：**野值概率 ~10⁻¹⁵，η = |d̂−d₀| ≈ 0.04–0.06 样本，纯局部误差**。即 −22~−26 dB 内一次性法的失败模式是模型失配（漂移），不是噪声。前导中心到包首还有 ν₀ ≈ P/2 ≈ 4 符号漂移前置。

**(ii) 包平均 SER。** 残余 κ_n = η + ε(n+ν₀)。argmax 在相邻两 bin（功率 ∝ Λ(⟨κ⟩) 与 Λ(1−⟨κ⟩)）间由指数噪声涨落裁决：
p_hop(κ) = Λ(1−⟨κ⟩)/[Λ(⟨κ⟩)+Λ(1−⟨κ⟩)] （κ=0.5 时 =½）, (5)
**P_err(κ) ≈ p_hop(κ) + (1−p_hop(κ))·P_M(ρ·Λ(⟨κ⟩))**, SER_one = (1/N_sym)Σₙ P_err(κ_n). (6)
"混跳区" w 由 p_hop(w/2) = 0.1 定：w ≈ 0.5–0.6 样本（与题设 0.6 一致），半宽 w/2 = 0.3。

**(iii) 地板条件（C2）。** 令 n* = (w/2−η)/ε − ν₀，地板
**SER_one^floor = (1/N_sym)·[N_sym − n*]₊ · p̄_hop ≈ (1/N_sym)·[ε(N_sym+ν₀)+η−w/2]₊/ε · p̄_hop**, p̄_hop ≈ 0.27, (7)
**出现地板 ⇔ ε(N_sym+ν₀) + η > w/2 (C2)**，临界漂移 ε_crit = (w/2−η)/(N_sym+ν₀) ≈ 0.25/39 = **0.0064 样本/符号**。台架 ε = 0.01 > ε_crit（1.5×）⇒ n* ≈ 21，跳变符号 14 个（κ: 0.31→0.44），**p_floor ≈ 0.10，且与 SNR 无关**。

## 2. 序列网格（本文）分析

**(i) 跟踪正确时的残余上界。** 条件 (A) 网格覆盖：|d̂_init − d[n]| ≤ 3Δ（7 态半宽 0.375；必要时重定心）且 (B) 无路径错误。则所选态满足 |ŝ_n − d[n]| ≤ Δ/2 = 0.0625，由 (1) Λ ≥ Λ(0.0625) = 0.987（−0.06 dB），γ_n ≥ 0.987ρ，p_base 膨胀 ≤ ×1.03——**量化损失可忽略是 Δ=0.125 合法的根据**。

**(ii) 跟踪错误概率（HML 序列辨识界）。** 发射 e[n,s] = log max_k|C_{d_s}[k]|²：正确态（Λ_c = 0.987）下峰 = 非中心 χ²₂（均值 1+ρΛ_c，log 域近似正态，方差 v_c ≈ 2/(ρΛ_c)）；错误态若丢音则峰 = L 个指数之 max（Gumbel）。最强（最易混淆的）**致害**错误态 = 刚出混跳区的格点，残余 0.3125，Λ_d = sinc²(0.3125) = 0.717。log 域等方差 KL 近似：
**KL_min(ρ) = Δm²/(2v̄), Δm = ln[(1+ρΛ_c)/max(1+ρΛ_d, ln L)], v̄ = ½(v_c+v_d), v_i = 2/(ρΛ_i)，当 1+ρΛ_i < ln L 时该态方差换成 π²/6.** (8)
（纯 H0 版本：KL(H1‖H0) ≈ [ln((1+γ)/(ln L+γ_E))]²/(2/γ + π²/6)。）逐符号独立发射下，ML 序列检测的并界（Forney 误差事件界的粗化形式）：
**P_track ≤ |S|^{N_sym}·exp(−N_sym·KL_min(ρ))**, (9)
其中 P_track 只对**致害**路径（残余 > w/2）取并——邻态混淆（残余 0.19，Λ=0.89）SER 无害，已从并中剔除。工程上更紧的事件形式：P_track ≲ 2|S|N_sym·Q(Δm·√L_div/√(2v̄))，L_div 为分叉长度。

**(iii)** 见 (2)。

## 3. 增益定理

**定理.** 设 C1：KL_min(ρ) ≥ (1/N_sym)·ln(|S|/η_t)（⇔ 由 (9) P_track ≤ η_t）；C2：ε(N_sym+ν₀)+η > w/2（⇔ p_floor > 0）。则
SER_one ≥ p_base + (1−p_base)p_floor, SER_seq ≤ p_base + η_t·p_max, p_max = ½,
**G ≡ SER_one − SER_seq ≥ (1−p_base)·p_floor − η_t·p_max ≥ p_floor − p_base − η_t/2 > 0 当 η_t < 2(1−p_base)p_floor.** (10)

**C1 破坏时的劣化机理（对应 −26 深端）。** KL 崩塌的根源是 (8) 中的悬崖：当 **ρ* = (ln L − 1)/Λ_d = 10.2（10.1 dB）** 时错误态发射均值 1+ρΛ_d 跌破噪声 max ln L = 8.32，发射退化为 Gumbel 噪声竞争，Δm 不变但 v̄ ×6，KL ÷7。此后 Viterbi 度量由噪声主导、路径在转移先验下随机游走；λ 的惯性偏置使错误路径**持续**（|Δs|≤1 锁死），残余被压在 0.3–0.5 长达包的剩余部分——突发式、相关误差，每符号 ≈ p_max = ½，超过一次性法仅在尾部 14 符号、均值 p̄_hop ≈ 0.27 的地板：P_track > 2p_floor/(1−p_base) 即 G < 0。

## 5. 可检验推论

1. **fd_c 的常数偏移**：SER(fd_c) ≈ P_M(0.987ρ) + p_floor，p_floor ≈ 0.09–0.12 在 −22…−26 **平坦**；即 fd_c 曲线与"无漂移/Genie 对齐"基线之间应存在 SNR 无关的 ≈6–12% 垂直间距，且其逐符号错误率在 n > n* ≈ 21 后尾重（seq 则平坦）。
2. **seq 的组成**：SER(seq) ≈ p_base + P_track·½：−22 时 ≈ p_base+≤0.03；−24 ≈ p_base+0.02–0.05；seq−fd_c 差值从 −0.075（−22）、−0.04（−24）变号为正（−26）。
3. **包长/漂移标度**：p_floor ∝ [ε(N_sym+ν₀)+η−w/2]₊：N_sym=70 ⇒ p_floor ≈ 0.19（seq 优势翻倍）；N_sym ≤ 25 或 ε < ε_crit = 0.0064 ⇒ 地板消失、两法重合。缩短 payload 或稳钟（ε<0.006）应使增益归零——可直接在台架上证伪。

## 6. 脆弱环节（各一句）

- **KL 近似**：等方差对数正态 + 逐符号独立 vs 真实"4096 相关 χ²₂ 之 max"（Gumbel 重尾）——加固：对合成漂移轨迹 Monte-Carlo 精确发射分布并列表 KL，替换 (8)。
- **漂移模型**：常数 ε vs 随机游走（钟漂抖动）——RW 下地板改为对 N(η, σ_ε²n) 积分 E[p_hop]，且 λ 须与真实漂移律重配（λ ↔ −ln P(Δs)），否则 P_track 上浮。
- **ρ 换算**：OS·BW vs BW 参考差 6 dB，直接平移翻转点——加固：向干净采集注入已知噪声、拟合实测 P_M 曲线反解有效 ρ 偏移（单参数标定），即可把 SNR* 钉死。
