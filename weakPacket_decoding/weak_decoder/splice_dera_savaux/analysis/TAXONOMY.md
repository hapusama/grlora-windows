# TAXONOMY — DERAfd×SAVAUX PER 失败分类学

日期：2026-10-05。脚本 `analysis/tax_run.py`（断点续跑 `analysis/tax_checkpoint.jsonl`，
252 单元，spawn 4 workers，1010s 墙钟）。研究问题：拼接战（data/experiments/
dera_savaux_splice_20261004）中 DERAfd×SAVAUX（DeRa 前端 top-5 候选 + 前导能量
分数时延精化 fd × Savaux 相干合并）在 −20/−22/−24 档的**每个 PER 失败单元到底
败在哪一层**。

## 1. 分类定义与口径

每个失败单元恰归一类（n=84/档 = 28 帧 × 3 种子）：

| 类 | 定义 |
|---|---|
| **成功** | top-5 候选（fd 精化后 Savaux 行）× δ∈{0,±1,±2} CRC 仲裁有一通过 |
| **1 sync-fail** | DeRa 前端在带噪段上检不出任何候选（`dera_sync` 空；含无可行长候选） |
| **2 coverage-fail 解调崩** | 全候选 CRC 败，且最优单候选 raw SER > 0.3（FEC 无从救） |
| **3 coverage-fail FEC 边缘** | 全候选 CRC 败，但最优单候选 raw SER ≤ 0.3（符号错太多 FEC 救不回） |

**raw SER 口径 = mode 冻结**（`debug_delay.py::ser_diff` 的推广）：
`d_k = (argmax(rows[k]) − (gt_k+1)) mod N`，δ_c = mode(d)，raw SER = mean(d≠δ_c)。
干净行 diff 为常数（{0:35} 或 {1023:35}），mode 即该候选固有 δ；raw SER 只度量
逐符号混跳/散射，与常数偏移无关（消除实验A"CRC 全败回退 δ=0 → 整帧记错"的
记账伪影，即 RESULTS §8 勘误在 fd 臂的延伸）。"最优单候选" = 逐候选冻结 δ=其
行 mode 后 raw SER 最低者。

**噪声逐位复用原实验**：`rng = default_rng((20260930·7919 + (level+100)·131 +
seed·17 + fi·7919) % 2³¹)`，`p_add = max(S/10^(level/10) − N0, 1e-30)`，S/N0 取
`sr.G["snr"][fi]`，seg 切法与 run_unit 逐字相同。**完整性验证：252/252 单元的
（失败=非成功类）与原 checkpoint DERAfd×SAVAUX crc_fail 逐位一致，0 失配。**
