## 创新点 1：问题测量——"同步参数选择损失"的首次量化 ✅

### 主张
弱信号下，前导同步参数造成的整包解码失败中，**大部分不是信息不足，而是
参数没对上**；这个损失可被干净测量，并分解为"参数型（可救）/信息型
（不可救）"两类。

### 证据与数字（G1 救援地图，SF10 真实 OTA 28 帧 × 3 种子，实验B 变体：
帧位置先验给定、GT/δ 冻结、AWGN 整包口径、CRC16 仲裁、固定解码器）

| 档 | A 臂（前导参数）失败 | B 臂（邻域搜索）救回 | C 臂（GT 拟合潜力） |
|---|---|---|---|
| −20 dB | 4/84 = 4.8% | 4/4 = 100% | 4/4 |
| −22 dB | 16/84 = 19.0% | 16/16 = 100% | 16/16 |
| −24 dB | 83/84 = **98.8%** | 64/83 = **77.1%**（TREL） | 83/83 |
| −24 dB（DERA 相干引擎） | 39/84 = 46.4% | 37/39 = **94.9%** | 39/39 |

- 参数型/信息型分解：TREL 引擎 77% vs 23%；DERA 相干引擎 95% vs 5%。
- 总覆盖（DERA 相干 + 65 点候选）≈ **98.8% 整包恢复**。
- 配对设计：同种子同噪声，引擎间差异无实现混淆。

### 边界
- **不是**误差影响分析（那是显然层：dechirp 后 CFO=频移、STO=时延、
  泄漏=sinc；Afisiadis'19/Xhonneux'22/Tapparel'25/QS-LEO'23 四篇已占
  单链单轴仿真版——见 doc/DTS_related_四篇省流）。
- **不是**解码器改进（解码器全程固定）。
- C 臂是离线诊断参照（用了 GT 选点），只证潜力上界、非算法性能——
  报数必带此声明（用户路线要求）。

### 抗质疑
- Q："多候选重试/参数扫描早有人做（DeRa Alg1 即是）"——A：我们贡献
  不是重试本身，是损失的**测量方法学与量化结论**（救援地图三臂设计），
  以及它揭示的结构（创新点 2）。DeRa 论文从未报告过"换参数能救回多少
  失败包"这个量。
- Q："会不会是 CRC 假阳性"——A：救援单元 GT 交叉核对通过（DERA 版
  救援点最低 SER 中位 0.000，97% ≤ 0.10，0% > 0.5）。

## 创新点 2：结构发现——同步参数空间的解码等价分层定律 ✅

### 主张
"哪些同步参数差异真正改变解码判决"第一次有了系统答案，且答案是分层的：

$$\text{净偏移 } e=\nu-\tau：
\begin{cases}
\text{能量层守恒（}\tau\text{ 与 }\nu\text{ 反向互消，成功区沿 }e=\text{const 展宽）}\\
\text{判决轨迹层完全不等价（类内 err\_mask 唯一模式率中位 1.00）}\\
\text{CRC 层大体一致（类内全一致率 83.9\%）}
\end{cases}$$

### 证据与数字
- **方向性硬证据（native，frame0）**：(ν=0.2, τ=0) TREL SER=1.0（全错）
  而 (ν=0.2, τ=0.2) SER=0（全对）——τ(chip) 的等效频移与 ν(bin) 反向，
  成败区域不是以估计点为中心的距离球。
- **等价类统计**（2268 个 net 类，≥3 点，全部 τ 混合类）：唯一 err_mask
  模式率中位 1.00（随机对照组 0.80）；CRC 全一致率 83.9%。
- **衍生定律**：结构引导（候选排序）的价值与解码器强度**反相关**——
  弱底座 TREL：等预算 2.2–2.9×；强底座 DERA 相干：1.4–1.9×，K≥9 被
  盲搜追平（相干合并成功区域更肥）。
- **次级现象**（未升格，待排除实现 artifact）：架构×残差交叉反转——
  native ε>0.075–0.1 bin 后朴素 argmax 反超全部精细链（ε=+0.3：
  PLAIN .103 vs DERA/TREL .42–.43）；三条精细链同涨同跌（ε=+0.5：
  .644/.647/.643）；±ε 方向不对称（+0.3 伤害 4× 于 −0.3）。

### 边界
- 净偏移守恒**只在能量层近似成立**——这正是"计算复用不能按等价类合并、
  必须判决分歧触发"的定量依据（用户警示被数据完全证实）。
- 交叉反转与精细链同死现象**未过实现排除**（κ 格加密消融 + DERA port
  相位约定单查），升格"架构矛盾"前必做。
- Xhonneux 的 CFO/STO 纠缠是**估计层**结论；我们的分层是**解码判决层**，
  两者互补且后者直接决定算法设计。

### 抗质疑
- Q："CFO/STO 等价是老知识"——A：估计层纠缠确实有（Xhonneux IoT-J'22）；
  判决层的三层分（能量/轨迹/CRC）无人做过，且它是算法（创新点 3）的
  直接设计依据。
- Q："结构会不会是数据集特异"——A：跨噪声（3 种子共享帧）内稳定；
  跨批次留出待补（自采/LoRadar，见路线图）。

## 创新点 3：算法——判决引导的候选集合相干解码器（COH-MULTI）🔶

### 主张
候选的**生成与调度由 payload 判决信息引导**（哪里改变判决往哪看），
而非检测峰排序（DeRa）；配深预算（K≫5）与谱 gather 复用（v2）。
形式：前导输出小候选集（含可信度）→ 每个物理一致假设下充分相干处理
（保留复数信息，共享参数约束补偿，S_i(m;θ)=|a_i+b_i·e^{−jφ_i(m;θ)}|²）
→ payload 参与选择 + 成本控制（判决分歧触发）。

### 证据与数字（W3-battle，−24 dB，DERA 相干引擎，84 单元）

| 臂 | 总整包恢复率 | 备注 |
|---|---|---|
| A0 单候选（=DeRa Stages 1–2） | 53.6% | |
| STAGE3 代理（5 候选重跑，net 序=对其有利） | 79.8% | 5 候选天花板实测 |
| RIDGE K=13（判决引导排序） | 95.2% | E[试验]=5.1 |
| RIDGE K=65（深预算） | **97.6%** | E[试验]=8.3 |

- 同 K=5 预算：RIDGE 救援 74% vs STAGE3 式 56% vs 盲序 54%
  （**排序值 18–20 个百分点**）。
- 同预算族完整曲线（TREL 与 DERA 两套地图，六策略：FIXED/BLIND-rand/
  BLIND-raster/NET-ladder/HIER-ladder/RIDGE-class/RIDGE-adaptive）见
  02_RESULTS §4/§6。

### 边界（如实）
- STAGE3 臂是**代理**：真 DeRa 候选按检测峰排序（20 池前 5），此处用
  net 距离序前 5——net 序是地图实测最优序之一，**代理对 DeRa 偏有利**
  （我方数字为保守下界）。去代理化 = 接其真实检测排序。
- RIDGE-adaptive（代表点 CRC 过才展开类内）**劣于**静态序（57% vs 77%，
  TREL 地图）——CRC 作类展开判据太硬，软判据（margin，已逐点存）是
  v2 修正方向。
- 复用引擎 v2 **未实现**：严格谱 gather（整窗高分辨率 FFT + 两段解析
  峰位 + 相位旋转合并）有峰位模型风险（port v1 曾死于峰位：native SER
  0.14），须单独一轮 + native 全对消融 + 与时域重算版逐位等价自校验
  （协议 §6）。当前耗时标定 0.17 s/候选（未优化 numpy），K=65 ≈ 3.3×
  包时长、非实时——主指标用候选重跑次数（实现无关）。

### 抗质疑
- Q："多候选重试 DeRa 有"——A：重试不是贡献。贡献=①往哪试的判据换了
  （检测峰→判决影响，18–20 pt 实测差）；②去掉 5 候选人为天花板
  （79.8%→97.6%）；③（v2）把 DeRa 只在检测段（§4.2 reusable FFT
  precomputation）做的复用延伸到 payload 段。**注意红线：DeRa 检测段
  已有候选间复用（gather-and-sum，Eq.19），"复用"本身不是我们首创——
  首创的是它在 payload 相干解码段的形态 + 判决分歧触发。**
- Q："为什么不直接把检测做强"——A：E3-lite 已证强前端（CERT sync 全档
  ≥DERA）仍留 ±0.2–0.3 bin 对齐误差且 PER 中段未胜——不确定性处理
  不可被前端替代。

## 创新点 4：评测框架——等预算真实 OTA 同表 🔶

### 主张
以**候选重跑次数**（实现无关）为主指标、**等预算盲枚举**为强制基线、
**真实 OTA 全链**为最终战场；判据健康用 GT 交叉核对（SER 分布）而非
裸 CRC。

### 现状
前三条创新点均在此框架内产出；**对 DeRa 实体的同表 PER 战（D1，含去
代理化 STAGE3 臂 + 端到端 exp A 形态）未跑**——见路线图 P0。
