## P0 —— 兑现战绩与补齐生死线（先做，顺序敏感）

### P0-1 D1：对 DeRa 实体的同表 PER 战（裁决实验）
- **目标**：把 W3 的代理胜利兑换成对实体的战绩（用户口径：只认 SER/PER）。
- **做法**：在 −24 dB（及 −22/−20）同表对比：
  1. DeRa 实体（其检测排序 + Stage 3 ≤5 候选，去代理化：port 其检测
     段排序逻辑或按其 §4.2 复现两级 FFT 候选池取前 5）；
  2. OURS-W3（判决引导排序 + K=13/65，DERA 相干引擎）；
  3. 等预算 BLIND；
  4. A0 单候选。指标=总整包恢复率 + E[候选数]。
- **验收**：OURS-W3 总恢复率 > DeRa 实体 ≥5 pt，且 E[试验] ≤ 对方×1.5。
- **依赖**：DeRa 检测排序 port（其代码标榜开源，先查 github；无则按
  §4.2 两级 FFT 复现，风险=复现偏差须声明）。

### P0-2 v2 复用引擎（论文主贡献的机制部分）
- **目标**：payload 段候选成本从"全重跑"降到 gather+相位旋转（候选增量
  成本目标 < 重跑的 1/10），使深预算（K=65）实时主张成立。
- **做法**：整窗高分辨率 FFT（每符号一次）+ 两段解析峰位（Eqs.10–11/
  wrap 模型）+ 相位旋转合并（用户公式形态）；**峰位模型为已知雷区**
  （port v1 曾死：native SER 0.14）——先在 native 干净段做全对消融，
  再与时域重算版逐位等价自校验（协议 §6），最后入噪声档。
- **验收**：native 判决与 port v2 逐位一致；−24 dB 恢复率不劣于重跑版
  超过 1 pt；单包 wall-time（K=65）≤ 1× 包时长。
- **风险**：峰位模型若需要精细校准，可退守"固定切分近似"版（次优切分
  损失需消融量化）——两个版本都做，报下界。

### P0-3 实现排除实验（DTS-1 交叉反转升格前置项）
- **做法**：①κ 格加密 0.25→0.125 消融（TREL 在 ε∈(0.1,0.3) 的崩塌若
  被格加密修复 ⇒ 支持"格间失配"机制）；②DERA port 相位约定单查
  （残差下的崩法是否 port 特有）；③三链共用前端排查（分数频偏预处理
  统一性）。
- **验收**：交叉反转现象在排除实验后仍然成立，或如实降级为"我方管线
  现象"。**在之前不得在任何文档写"架构矛盾"级结论。**
